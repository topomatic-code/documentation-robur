# Перед установкой

Для установки ПК «{{robur}}» обязательно требуются права локального администратора. Дистрибутивы для установки можно скачать здесь:

[https://topomatic.ru/products/](https://topomatic.ru/products/)

Убедитесь, что на диске имеется достаточно свободного места. По умолчанию ПК «{{robur}}» устанавливается в папку «`ProgramFiles\Topomatic Robur`».

При необходимости вместе с ПК «{{robur}}» устанавливаются драйвер ключа HASP и Microsoft.Net Framework (если они не были установлены ранее).
