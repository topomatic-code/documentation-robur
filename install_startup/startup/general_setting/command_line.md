# Командная строка

С помощью **Командной строки** удобно просмотреть, при необходимости, список команд и процессов, которые выполнялись в проекте за текущий период. Также она удобна для ввода некоторых команд, имеющих параметры, которые проще всего выполнить, введя соответствующий символ или значение в командную строку.

Кроме того, список доступных команд для вызова тех или иных инструментов программы можно посмотреть в меню **Сервис - Настройка панелей инструментов** (см. подробнее в разделе [Адаптация](workspace.md)).

Чтобы открыть **Командную строку**, выберите меню **Вид – Командная строка ![](_media/interface_program6.png)**. Таким образом она добавится на **Панель активности** (если ранее еще не была добавлена) и откроется.

Чтобы добавить **Командную строку** на ту или иную **Панель активности** самостоятельно, щелкните по ней ПКМ и в контекстном меню выберите пункт **Командная строка**.

Подробнее о **Панелях активности** см. здесь: [Интерфейс программы](../startup_program/interface_program.md)
