# Удаление элементов

Данная функция позволяет удалить выбранный элемент с проектной поверхности.

Для этого:

1. Выберите элемент меню **Задачи - Площадки - Площадки (Архив) - Удалить объект**.
2. Левой кнопкой мыши укажите на плане участок, принадлежащий удаляемому элементу.

В результате с проектируемой поверхности будет удалены все контуры, линии, точки и треугольники, принадлежавшие данному элементу.
