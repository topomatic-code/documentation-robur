# Разрыв элементов

Данная функция позволяет разрывать выбранный элемент в заданной точке. К примеру, это может потребоваться, если на определенном участке уже созданному бортовому камню необходимо присвоить другую марку, или уже созданной дорожке требуется задать другую толщину конструкции.

Для разрыва элемента:

1. Выберите элемент меню **Задачи - Площадки - Площадки (Архив) - Разорвать объект**.
2. Левой кнопкой мыши укажите на плане участок объекта, который необходимо разделить на части.
3. Укажите левой кнопкой мыши точку на объекте где необходимо выполнить разрыв.

В результате исходный объект будет разбит на части, которые в последствии, могут редактироваться не зависимо друг от друга.

{% note info %}

 Данная функция применима не для всех элементов проектируемой площадки.

{% endnote %}
