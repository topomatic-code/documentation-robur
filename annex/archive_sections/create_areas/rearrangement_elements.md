
# Перестроение элементов

Данная функция позволяет производить обновление объектов при изменении положения их исходных контуров на плане. К примеру, при незначительном изменении планового положения здания, нет необходимости удалять и создавать его заново, т.к. остальные его параметры (УЧП, отмостка и т.п.) остались неизменными.

Для перестроения заданного элемента:

1. Выберите элемент меню **Задачи - Площадки - Площадки (Архив) - Перестроить объект**.
2. Левой кнопкой мыши укажите на плане участок, принадлежащий перестраиваемому элементу.

В результате объект будет перестроен с учетом изменения его исходного (базового) контура.
