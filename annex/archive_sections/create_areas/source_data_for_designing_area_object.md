
# Исходные данные для проектирования площадного объекта

Площадка представляет собой модель типа **ЦММ**. В качестве исходных данных для проектирования площадки необходима поверхность существующей земли. Также в случае примыкания проектируемой площадки к линейному объекту (например - автомобильной или железной дороге), проект должен содержать модели соответствующих типов.
