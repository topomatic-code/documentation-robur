# Общие Тэги чертежей для моделей подобъектов Железных дороги и Автомобильных дорог.

### Тэги для определения параметров формирования чертежа (масштабы, формат листа, название) по умолчанию в Мастере создания чертежа продольного профиля:

1. **&TITLE** - описание шаблона, отображаемое на первом шаге Мастера формирования чертежа продольного профиля.
2. **&LV и &LH** - горизонтальный и вертикальный размеры листа, определяемые по умолчанию.
3. **&SH, &SV и &SG** – горизонтальный масштаб, вертикальный и масштаб грунтов, определяемые по умолчанию.

### Теги для формирования данных с профилей:

1. **&CP «Параметр»** - выносит на чертеж линию дополнительного профиля В поле «Параметр» записывается Имя дополнительного профиля.

  {% note info %}

  Если имя дополнительного профиля содержит пробелы, то его необходимо заключать в кавычки, например, &CP “профиль 1”.

  {% endnote %}

### Формирование данных по плановой части подобъекта

1. **&PKT** – пикетаж
2. **&K** – километраж. Числовое значение после тэга задает точность вывода расстояний до предыдущего пикета («плюсовки»)
3. **&UP** - развернутый план. Числовое значение после тэга задает ширину развернутого плана в единицах чертежа.

### Формирование геологических данных

1. **&PLAN\_BOREHOLES** - снесение и отрисовка на развернутом плане геологических выработок.
2. **&GEOLOGY\_GROUNDS\_HATCHES** - отрисовка заливки\штриховки геологических контуров.
3. **&GEOLOGY\_CONTOURS** - отрисовка геологических контуров
4. **&GEOLOGY\_BOREHOLES** - отрисовка геологических выработок
5. **&GEOLOGY\_ASSAYS** - отрисовка опробования грунтов
6. **&GEOLOGY\_FROST** - отрисовка линии вечной мерзлоты
7. **&GEOLOGY\_WATER** - отрисовка линии уровня грунтовых вод
8. **&GEOLOGY\_NOTES** - отрисовка подписей шифров и категорий разработки грунтов
9. **&GEOLOGY\_LEGEND** - отрисовка таблицы Инженерно - геологических элементов

### Прочее

1. **&ABS\_ELEVATIONS\_RANGE\_LINE** - линейка абсолютных высот
2. **&COMMUNICATIONS** - отрисовка коммуникаций
3. **&ET** - отрисовка таблицы неумещающихся отметок
4. **&L** – формирование горизонтальной линии.
