# Основные коды (Тэги) используемые в стандартных шаблонах чертежа продольного профиля Автодорожных подобъектов

### Формирование данных по различным линиям продольного профиля (уклоны, расстояния и отметки):

1. **&PP** - линия проектного продольного профиля
2. **&AP** - линия интерполированного профиля
3. **& G** «параметр» - уклон, длина и вертикальная кривая по проектному профилю.
4. **& D** «параметр» – расстояние по профилю.
5. **& E** «параметр» – отметки по профилю.

   * «Параметр» может принимать следующие значения:

     * PRF – проектный продольный профиль
     * CHZ – фактический продольный профиль
     * CHI – интерполированный (дополнительный) продольный профиль
     * Имя дополнительного профиля
     * Код рассекаемой поверхности
<br>
6. **&PLN-ROAD** - элементы плана трассы (прямые и кривые). Числовые значения после тэга задают точность вывода значений радиусов и переходных кривых, длин тангенсов и кривых, пикетов по границам кривых соответственно.

### Формирование данных по профилю водоотвода:

1. **&TG PRF L\R** - формирует уклоны и расстояния по выбранному профилю в качестве Левого и Правого лотков в поле Параметры чертежа на Шаге 2. мастера формирования чертежа продольного профиля.
2. **&TE PRF L\R** - формирует отметки по выбранному профилю в качестве Левого и Правого лотков в поле Параметры чертежа на Шаге 2. мастера формирования чертежа продольного профиля.
3. **&DG PRF «параметр»** - формирует уклоны и расстояния по профилю водоотводного сооружения (кюветам, канавам), отфильтровывая участки с рабочими отметками более или равные нулю.
4. **&DE PRF «параметр»** - формирует отметки по профилю водоотводного сооружения (кюветам, канавам) отфильтровывая участки с рабочими отметками более или равные нулю.

«Параметр» может принимать числовые значение от 1 до 18, которые соответствуют порядковым номерам профилей, которые могут быть созданы по смещениям. Например параметр 1 - соответствует 1-му левому профилю, параметр 2 - соответствует 1-му правому профилю и т.д.
