# Основные коды (Тэги) используемые в стандартных шаблонах чертежа продольного профиля Железнодорожных подобъектов

### Формирование данных по различным линиям продольного профиля (уклоны, расстояния и отметки):

1. **&RG PRF** - уклон, длина и вертикальная кривая по проектному профилю;
2. **&RD** - засечки по границам кривых и переломам проектного профиля;
3. **& D «параметр»** – расстояние по профилю;
4. **& E «параметр»** – отметки по профилю.

#### «Параметр» может принимать следующие значения:

* CHZ – фактический продольный профиль
* CHI – интерполированный (дополнительный) продольный профиль
* Имя дополнительного профиля
* Код рассекаемой поверхности

### Формирование различных данных чертежа продольного профиля

1. **&RPP** - отрисовка линии проектного профиля и вертикальных ординат по границам элементов проектного профиля.
2. **&RPC** - отрисовка вертикальных кривых над шапкой чертежа. (при включении соответствующей настройки в текущей модели в параметрах отображения кривых для железнодорожного профиля (Над шапкой))
3. **&EW** - отображает рабочие отметки в местах переломов черного профиля, по границам и элементам линии проектного профиля.
4. **&EР** - отрисовка линии черного профиля
5. **&AP** - отрисовка линии интерполированного профиля
6. **&RRH** - отрисовка линии расчетной головки рельса
7. **&EBL** - отрисовка линии существующего балласта
8. **&JW 15 20** - отрисовка схемы раскладки плетей бесстыкового пути. Числовые значения после тега определяют расстояние смещения данных (плетей, подписей и пикетажны значений сварных и изолирующих стыков и т.д.) относительно точки вставки тега.

### Формирование данных с плановой части подобъекта:

1. **&PLN-RAIL 0 2 2** – элементы плана трассы (прямые и кривые). Числовые значения после тэга задают точность вывода значений радиусов и переходных кривых, длин тангенсов и кривых, пикетов по границам кривых соответственно.
2. **&RADIUS** - радиусы вершин углов поворотов. Числовое значения после тэга задает точность вывода значений радиусов.
3. **&ANGLE** - значения углов поворота.

### Формирование дополнительных данных по подобъекту

1. **&EBT** - толщина существующего балластного слоя

2. **&РBT** - толщина проектного балластного слоя

3. **&MP UP** - формирование данных по исправлению продольного профиля (повышение)

4. **&MP DOWN** - формирование данных по исправлению продольного профиля (понижение)

5. **&MPG 10** - отображение исправлений продольного профиля (превышений и понижений) в виде графика. Числовое значения после тэга через пробел задает высоту графика (в мм).

6. **&STR** «параметр 1» «параметр 2» «параметр 3» «параметр 4» - формирование данных по сдвижкам оси пути

* «Параметр 1» - принимает значение L и R, где,

  * **L** - формирование данных по сдвижкам оси пути (лево)
  * **R** - формирование данных по сдвижкам оси пути (право)

* «Параметр 2» - принимает следующие числовые значения и их комбинации:

  * **1** - точки с шагом
  * **2** - точки существующего пути
  * **4** - шаг от целых пикетов
  * **8** - интерполировать значения

  {% note info %}

  Комбинации формируются как сумма этих значений, например 14 = 2 + 4 + 8 - выводить точки с шагом, от целых пикетов и интерполировать значения.

  {% endnote %}

* «Параметр 3» - шаг вывода значений (м) на прямых участках
* «Параметр 4» - шаг вывода значений (м) на криволинейных участках

Пример использования тэга - **&STR L 1 20.0 15.0**

1. **&STRG** «параметр 1» «параметр 2» «параметр 3» «параметр 4» - формирование графика рихтовок

* «Параметр 1» - принимает числовое значение, которое определят высоту графика.
* «Параметр 2» - принимает следующие числовые значения и их комбинации:

  * **1** - точки с шагом
  * **2** - точки существующего пути
  * **4** - шаг от целых пикетов
  * **8** - интерполировать значения

  {% note info %}

  Комбинации формируются как сумма этих значений, например 14 = 2 + 4 + 8 - выводить точки с шагом, от целых пикетов и интерполировать значения.

  {% endnote %}

* «Параметр 3» - шаг вывода значений (м) на прямых участках
* «Параметр 4» - шаг вывода значений (м) на криволинейных участках

Пример использования тэга - **&STR 10 1 20.0 15.0**

### Формирование данных по профилю водоотвода

1. **&DRAINAGE\_BOTTOM\_WIDTH** - ширина дна водоотводного сооружения
2. **&DRAINAGE\_SCHEME** - схема водоотводов (отрисовка направления водотока и расстояния от оси пути до оси водоотводного сооружения)
3. **&DRAINAGE\_LINE EDG** - формирование линий черного профиля по бровке водоотводного сооружения
4. **&DRAINAGE\_LINE** - формирование линии черного профиля по центру дна водоотводного сооружения.
5. **&DRAINAGE\_CL** - уклоны и расстояния по оси пути
6. **&E EDG** - отметки черному профилю по бровке водоотводного сооружения
7. **&D EDG** - расстояния по черному профилю по бровке водоотводного сооружения
