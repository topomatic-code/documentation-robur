# Основные этапы и понятия

Данный программный модуль позволяет, на основании съемочных данных существующего пути, рассчитывать и выправлять его прямолинейные и криволинейные участки. В процессе расчетов автоматически формируются необходимые графики, наглядно демонстрирующие искомые кривые, формируется отрихтованная ось и создается ведомость рихтовок.

Исходными данными являются точки существующего пути, снятые с необходимым интервалом.

Решение задачи по расчету рихтовок включает в себя следующие этапы:

1. Создание подобъекта рихтовок и задание существующего пути.
2. Назначение прямолинейных и криволинейных участков. Получение первого приближения отрихтованного пути.
3. Формирование графика кривизны.
4. Редактирование прямолинейных и криволинейных участков.
5. Формирование ведомости рихтовок.

Основные используемые термины:

* **Подобъект рихтовок** – отрихтованная трасса, созданная на основе данных по существующему пути. С ней работают основные функции рихтовок.
* **Существующий путь** – трасса, или произвольный линейный объект, который используется для заполнения таблицы координат существующего пути.
