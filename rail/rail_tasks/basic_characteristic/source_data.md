
# Исходные данные для проектирования вторых путей

В качестве исходных данных необходимых для проектирования вторых путей, как правило, используется снятый изыскателями существующий путь, профиль по СГР полученный по результатам съемки, черные поперечные профили и геологические данные нанесенные на продольный и поперечные профили.

**Существующий путь** – подобъект, план которого создан из примитивов. В качестве примитивов может выступать обведенная по снятым точкам структурная линия или полилиния, подгруженная из любого графического редактора. Профиль по СГР может быть получен построением черного продольного профиля по данным нивелирной съемки, либо импортирован/забит вручную в таблицу Черный профиль, в окне **Структура проекта**.

Черные поперечные профили могут быть получены сечением цифровой модели рельефа, при ее наличии, либо забиты вручную в формате **Смещение от оси – Отметка**, а также сформированы по съемочным точкам.
