# Открытие окна редактора геодезических измерений

Для редактирования данных съемки:

1. В окне **Структура проекта** дважды щелкните левой кнопкой мыши по наименованию съемки, которую необходимо отредактировать. В результате откроется окно геодезического редактора, наименование которого будет совпадать с названием текущей съемки.
2. Для того чтобы иметь возможность одновременно редактировать измерения и видеть результаты работы в окне **План**, необходимо открепить вкладку съемки и воспользоваться имеющимся функционалом по организации рабочего пространства (например, выбрать меню **Окно - Организовать горизонтально**).

{% note info %}

 Для рассмотрения более подробного описания механизма работы с окнами программы см. документацию [Рабочие окна](../../install_startup/startup/startup_program/setting_working_windows.md).

{% endnote %}

В результате окно геодезического редактора будет расположено в требуемой части графического поля. Далее рассмотрим его основные вкладки.
