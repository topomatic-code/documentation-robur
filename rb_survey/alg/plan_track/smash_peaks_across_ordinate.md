# Разбить вершины по ординате

Функция позволяет разбить кривую на несколько составных, как правило, это необходимо, чтобы уменьшить значение биссектрисы угла при разбивке кривой на местности.

Для этого:

Выберите меню **План - Разбить вершины по ординате**, в динамической строке ввода задайте максимальное значение ординаты и нажмите **Enter**:

![рис.1](_media/smash_peaks_across_ordinate.jpg)

В результате все вершины плана трассы с учетом заданной максимальной ординаты будут разбиты на составные кривые.

{% note info %}

 Для разбивки одной вершины угла нажмите правой кнопкой мыши на необходимой вершине угла, выберите элемент меню **Разделить по ординате**.

{% endnote %}
