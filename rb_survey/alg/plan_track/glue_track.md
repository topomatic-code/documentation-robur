# Склейка трасс

Данная функция позволяет производить объединение двух трасс, стыкующихся в общей точке. Трассы, как правило, получены с помощью функции **[Разбить подобъект](cutting_track.md)**. В результате создается новая трасса, полученная объединением двух исходных.

Для этого:

* До начала склейки трассы сделайте текущим подобъект, который должен быть получен объединением двух исходных. При необходимости создайте новую трассу.

  {% note info %}

  Последовательность действий по созданию новой трассы была описана в разделе **[Структура проекта](../../../install_startup/startup/structure_project/structure_project.md)**.

  {% endnote %}

1. Выберите элемент меню **План - Склеить подобъект**. Появится диалоговое окно:

   ![рис.1](_media/plan_trackglue_track.png =500x198)

2. В поле **Подобъект слева** и **Подобъект справа** введите наименования трасс, которые необходимо склеить. Их также можно выбрать из общего списка трасс, которые содержит текущий проект, воспользовавшись кнопкой **Обзор**.
3. Нажмите кнопку **ОК**.

   {% note info %}

   Склеиваться могут трассы, имеющие общую точку. Если склеиваемые трассы имеют продольные профили, то они также должны иметь общую точку стыковки. В противном случае склейка будет невозможна.

   {% endnote %}
