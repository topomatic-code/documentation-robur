# Удаление трассы

Функция предназначена для удаления текущей трассы.

Для этого:

1. Выберите пункт меню **План - Удалить ось**.
2. В появившимся окне подтвердите намерение удалить текущую трассу, нажав для этого кнопку **Да**.

   ![рис.1](_media/delete_road.png =250x156)

В результате текущая ось будет удалена.
