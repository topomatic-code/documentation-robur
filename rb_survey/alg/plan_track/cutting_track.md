# Разбить подобъект

Данная функция позволяет разбить текущий подобъект на две части. При этом исходная трасса остается неизменной. При разбивке оси создаются копии для ее левой и правой части. Разбивке может подлежать не только плановая геометрия трассы, но и все данные, которые она содержит (продольный профиль, список поперечников, геологический разрез и т.п.).

Для разрезки трассы:

1. Выберите элемент меню **План – Разбить подобъект**. Появится диалоговое окно:

   ![рис.1](_media/cutting_track.png =500x222)

2. В поле **Пикет** задайте пикетажное значение точки разбивки.

   Ее также можно указать графически. Для этого нажмите кнопку ![рис.2](_media/cutting_track2.jpg). Перемещая курсор вдоль исходной трассы, щелкните левой кнопкой в том месте, где ее требуется разбить.

3. В полях **Подобъект слева** и **Подобъект справа** задайте наименования вновь создаваемых трасс, получаемых после разрезки исходной.

4. Нажмите кнопку **Ок**.

В результате будут созданы две новые трассы, стыкующиеся между собой в указанной точке разрезки.
