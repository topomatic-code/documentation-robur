# Сопряжение двух окружностей усеченной клотоидой

Чтобы сопрячь две окружности/дуги усеченной клотоидой:

1. Выберите элемент меню **Рисовать – Построения – Сопрячь две окружности усеченной клотоидой**.
2. Последовательно укажите две окружности/дуги. Программа подберет несколько вариантов сопряжения и отобразит их на экране.

   ![рис.1](_media/conjugation_truncated_clothoid.png =300x280)

3. Левой кнопкой мыши укажите нужный вариант сопряжения.
4. Для выхода из данной функции нажмите правую клавишу мыши, для завершения работы команды нажмите **Esc**.
