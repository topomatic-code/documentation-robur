# Построение окружности от клотоиды

Данное сопряжение позволяет построить окружность от любой точки клотоиды. Для построения сопряжения:

1. Выберите элемент меню **Рисовать – Построения – Окружность от клотоиды**. Курсор примет форму прицела.
2. Левой кнопкой мыши укажите клотоиду. Программа построит окружность радиусом равным радиусу клотоиды в точке сопряжения, откроется диалоговое окно: 

   ![рис.1](_media/create_circle_from_clothoid.png =400x299)

3. В открывшемся диалоговом окне задайте один из параметров сопряжения, второй параметр программа подберет автоматически.

   Также параметры сопряжения пользователь может изменять графически, перемещая мышкой точку сопряжения.

4. Для выхода из данной функции нажмите правую клавишу мыши или выберите **Готово**.
