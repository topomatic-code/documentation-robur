# Смещение линейного объекта

Функция **Сместить линейный объект** позволяет отрисовать линейный объект примитивом со смещением на заданное расстояние. Например, эту функцию удобно применять при плановых построений с использованием функций основного меню **Рисовать – Построения**.

Данный способ смещений позволяет наиболее точно смещать линейный объект (*например, арка, прямая, клотоида и т.д.*) сохраняя геометрические размеры исходного объекта. Для этого:

1. Выберите меню **Рисовать – Построения – Сместить линейный объект**.
2. В строке динамического ввода задайте расстояние, на которое будет смещен объект, и нажмите Enter.
3. Выберите исходный объект и укажите сторону смещения. При необходимости повторите действия. Для выхода из команды нажмите ПКМ.

   {% note info %}

   При смещении окружности или круговой кривой оси укажите пикет начала и конца участка смещения, а затем сторону смещения.

   {% endnote %}

В результате линейный объект будет отрисован со смещением на заданное расстояние.
