# Добавить поперечник

Чтобы добавить дополнительный поперечник к списку на заданном пикете, выполните следующие действия:

1. Выберите пункт меню **Поперечники - Добавить поперечник**. Откроется диалоговое окно:

   ![рис.1](_media/insert_additional_diameter.gif)
   
2. Введите пикет, на котором нужно вставить поперечник и выберите **OK**.
