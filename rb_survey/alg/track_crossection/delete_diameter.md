# Удаление поперечника

Функция предназначена для удаления текущего поперечника. Для этого:

1. Выберите элемент меню **Поперечник - Удалить поперечник**. Появится диалоговое окно:

   ![рис.1](_media/delete_diameter.png =300x166)

2. Выберите кнопку **Да**. При этом текущий поперечник будет удален.

{% note info %}

 Если черный поперечник редактировался табличным способом, а затем был удален из списка, то табличные данные автоматически не удаляются и сохраняются при последующем создании поперечника на этом пикете.

{% endnote %}
