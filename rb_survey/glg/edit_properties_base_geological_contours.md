# Редактирование свойств базового геологического контура

По умолчанию данному контуру не соответствует какой-либо грунт заполнения. Для его задания:

1. Выберите элемент меню **Задачи - Геология -Свойства ограничивающего контура**. Откроется следующее окно:

   ![рис.1](_media/edit_properties_base_geological_contours.png =500x549)
   
2. Для выбора грунта заполнения нажмите кнопку ![рис.2](_media/surface_across_code2.jpg) расположенную за полем **Грунт**.
3. Из раскрывшейся таблицы грунтов двойным щелчком мыши выберите грунт, который должен быть присвоен ограничивающему контуру.
4. Нажмите **Ок**.

В результате, свободное пространство базового контура, не заполненное другими геологическими слоями, будет заполнено выбранным грунтом.
