# Термины и определения

* **Общая таблица лаборатории** – специальный табличный редактор проб грунтов. Предназначена для централизованного хранения, редактирования проб грунтов, а также ведения статистической обработки.
* **Глобальная таблица лаборатории** (в модели **Геология**) – специальный табличный редактор проб грунтов, внутри **Глобальной таблицы выработок** (см. раздел [Создание таблицы глобальных выработок](../creation_table_global_workings.md)). Предназначена для распределения (связи, анализа и графического отображения) проб грунтов по колонкам выработок. Пробы грунтов могут быть импортированы сюда из **Общей таблицы лаборатории** и **Локальной таблицы лаборатории**.
* **Локальная таблица лаборатории** (в модели трассы/дороги) - специальный табличный редактор проб грунтов, внутри **Локальной таблицы выработок** (см. раздел [Создание таблицы выработок](../creation_table_workings.md)). Предназначена для распределения (связи, анализа и графического отображения) проб грунтов по колонкам выработок. Пробы грунтов могут быть импортированы сюда из **Общей таблицы лаборатории** и **Глобальной таблицы лаборатории**.
* **Шаблоны лабораторной таблицы** - это **Общие таблицы лаборатории** с настроенным видом «шапки» и параметрами столбцов (см. раздел [Управление таблицей](table_management.md)). Шаблоны лабораторной таблицы бывают **Системными** и **Пользовательскими** (см. разделы [Системные шаблоны](description_template.md) и [Работа с Пользовательским шаблоном](description_template.md)).
* **Ключевые столбцы таблицы лаборатории** – столбцы, однозначно характеризующие наличие пробы. Таких столбцов всего четыре - *«Номер выработки», «Глубина взятия пробы», «Глубина взятия пробы (конечная)», «Тип пробы (значок)»*.
* **Идентификатор** – уникальный адрес столбца таблицы лаборатории.  

   Идентификаторы **Ключевых столбцов**:  

   `BoreholeNumber` - Номер выработки.  
   `AssayDepth` - Глубина взятия пробы.  
   `AssayDepthEnd` - Глубина взятия пробы (конечная).  
   `AssayTypeSign` - Тип пробы (значок).

  {% note warning %}

  Наличие в таблице лаборатории столбцов с идентификаторами, указанными выше, необходимо для корректной работы программы.

  {% endnote %}

* Кроме идентификаторов **Ключевых столбцов** может потребоваться наличие дополнительных столбцов со следующими идентификаторами:  

   `Phys\_Density` - столбец с показателями плотности грунта при естественной влажности. Необходим для работы функции **Автопробы**.  

   `Ground\_Cipher` - столбец со значением шифра грунта (ИГЭ). Необходим для работы функций **Фильтр по шифру грунта**, **Задействованные грунты** и для создания **Сводной и нормативной ведомостей**.  

   `Ground\_Name` - столбец со значением наименования грунта. Необходим для работы функции **Задействованные грунты**.  

   `Enabled` - столбец с опцией, необходимой для назначения строки в качестве **Активной строки**.  

   `Highlighted` - столбец с опцией, необходимой для выделения строки цветом.

  {% note info %}

  **Системные шаблоны** (кроме шаблона xEmpty) уже содержат все столбцы с выше указанными идентификаторами (подробнее о шаблонах см. в разделе [Шаблоны](description_template))

  {% endnote %}

* **Активные строки** - строки, при включенной опции в столбце «Активность». Такие строки участвуют в статистических расчетах и распределении по выработкам.
* **Расчетные строки** – это отфильтрованные пробы (строки) по шифру грунта (ИГЭ) (см. описание **Фильтра по шифру грунта** в разделе [Статистическая обработка результатов испытаний](statistical_processing_results_testing.md)).
* **Сводные строки** – строки, содержащие сводный итог расчета показателей проб по расчетным активным строкам. Отображаются при активном **Фильтре по шифру грунта** и визуально отличаются от основных строк (проб).
