# Объединение объектов

При помощи данной команды можно соединять различные объекты линейного типа. Необходимо чтобы соединяемые объекты находились на одном уровне. Для каждого типа объекта имеются свои условия, необходимые для выполнения данной функции.

Ограничения накладываемые на объединяемые объекты:

* **Линии** - объекты данного типа должны лежать на одной прямой, а их начальные и конечные точки должны совпадать.
* **Полилинии** - эти объекты должны лежать в одной плоскости и между ними не должно быть зазоров.
* **Дуги** - должны лежать на одной воображаемой окружности и между ними должны быть зазоры.
* **Эллиптические дуги** - должны лежать на одном воображаемом эллипсе и между ними должны быть зазоры.
* **Сплайн и спираль** - эти объекты должны быть непрерывными от начала до конца.

Для того, чтобы соединить объекты выполните следующие действия:

1. Выберите элемент меню **Редактировать – Соединить** или кнопку ![рис.1](_media/joinder_objects.jpg) на панели инструментов, либо введите `join` в командную строку.
2. Выделите исходный объект.
3. Укажите объект, который необходимо объединить с исходным объектом.
4. Нажмите правую кнопку мыши, либо **Enter**. Программа соединит выбранные объекты.

**Применимость команды**: Команда **Соединить** применима только для редактирования элементов чертежа.
