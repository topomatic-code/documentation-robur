# Разрыв объектов в двух точках

Данная команда предназначена для разрыва объекта в двух указываемых точках.

Для этого:

1. Выберите элемент меню **Редактировать – Разорвать** или кнопку ![рис.1](_media/gap_in_two_dots.jpg) на панели инструментов, либо введите `break` в командную строку.
2. Выделите левой кнопкой мыши объект для разрыва.
3. Укажите последовательно первую и вторую точку разрыва.

**Применимость команды** Команда **Разорвать** применима только для редактирования элементов чертежа.
