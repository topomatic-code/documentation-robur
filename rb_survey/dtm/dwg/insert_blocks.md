# Вставка блоков

Для вставки заранее созданных блоков:

1. Выберите элемент меню **Рисовать – Блок – Вставить блок** или кнопку ![рис.1](_media/insert_blocks.jpg) на панели **Рисовать**, либо введите `insert` в командную строку. Откроется диалоговое окно:

   ![рис.2](_media/insert_blocks2.png =646x416)

2. В раскрывающемся списке **Имя**, выберите наименование вставляемого блока, либо воспользуйтесь кнопкой **Обзор**. Откроется окно **Выбор файла чертежа**, в котором необходимо выбрать файл чертежа (выбранный чертеж будет вставляться, как блок). Данная опция позволяет подгружать следующие форматы чертежей:
   * Чертежи Robur (dwp).
   * XML-файлы.
   * DXF-файлы.
   * Чертежи Robur (dwr).
3. Вставьте блок в чертеж. Данная операция происходит следующим образом:

   В области **Точка вставки** задайте координаты базовой точки блока. При включенной опции **Указать на экране**, после закрытия данного окна точка вставки будет отдельно запрошена программой. При выключенной опции для ввода доступны поля X, Y, Z, в которые нужно вести координаты базовой точки вставки.

   В области **Масштаб** при необходимости введите масштабные коэффициенты, с которыми блок будет вставляться в чертеж. Если все три масштабных коэффициента равны 1 (X=1, Y=1, Z=1), то блок будет вставлен с теми же размерами, какие были у исходных объектов. Если какой-то из масштабных коэффициентов меньше 1, то блок сжимается вдоль по этой оси, если больше 1 – растягивается с данным масштабным коэффициентом по этой оси. Масштабный коэффициент может быть и отрицательный, тогда изображение блока по этой оси будет зеркально отражено.

   При установленной опции **Указать на экране** после закрытия окна необходимо будет **Указать масштаб визуально**. В этом случае он будет един для всех координатных осей.

   Если установить опцию **Равные масштабы**, поля Y и Z будут недоступны, а заданное значение в поле X становится значением масштабных коэффициентов по всем трем осям.

   В области **Угол поворота** задается угол поворота блока вокруг точки вставки. Поворот против часовой стрелки имеет положительное значение, поворот по часовой стрелки задается с отрицательным значением. При установленной опции **Указать на экране**, после закрытия данного диалогового окна угол поворота будет отдельно запрошен программой.

   Опция **Расчленить**, расположенная в левом нижнем углу диалогового окна предназначена для вставки блока “разбитого” на исходные примитивы из которых он создавался.
