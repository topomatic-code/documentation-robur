# Копирование объектов

Данная команда позволяет копировать выбранные объекты на заданное расстояние. Копирование происходит путем задания начального положения базовой точки (точка привязки объекта) и ее конечного положения.

Методы копирования:

* **Метод базовой и конечной точки**. Данный метод заключается в задании перемещения и направления. О создании копий данным способом описано ниже.
* **Метод сдвига**. Задаются числовые значения перемещений по координатной оси X и Y. Этот способ применим в тех случаях, когда сдвиг объекта заранее известен.

Для того, чтобы воспользоваться данным способом необходимо после выбора объекта, на запрос указать базовую точку, нажать **Enter**. Далее через координаты X,Y в командную строку ввести значение перемещения.

Способы переноса объекта:

* При помощи задания абсолютных координат.
* По заданию расстояния и угла.
* Относительное смещение.

Для того, чтобы скопировать объекты выполните следующие действия:

1. Выберите элемент меню **Редактировать – Копировать или кнопку** ![рис.1](_media/copying_objects.gif) на панели инструментов, либо введите `copy` в командную строку.
2. Указав объекты для копирования, нажмите правую кнопку мыши или нажмите **Enter**.
3. Укажите базовую точку.
4. Скопируйте объекты любым из трех возможных способов переноса. Для этого нажмите правую кнопку мыши, появится контекстное меню, в котором выберите опцию **Курсор**. При выборе данной опции откроется еще одно контекстное меню, в котором представлены способы переноса объекта.
5. Для выхода из режима копирования и подтверждения ввода нажмите **Enter**.

**Применимость команды:**

Команда **Копировать** применима для редактирования чертежей, объектов **ЦММ** и **Трасс.**
