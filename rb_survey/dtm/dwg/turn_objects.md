# Поворот объектов

Данная команда дает возможность повернуть выбранные объекты вокруг базовой точки на заданный угол.

Для этого:

1. Выберите элемент меню **Редактировать – Повернуть** или кнопку ![рис.1](_media/turn_objects.jpg) на панели инструментов, либо введите `rotate` в командную строку.
2. Выделите секущей рамкой или левой кнопкой мыши объекты для редактирования. После чего нажмите правую кнопку мыши, либо **Enter**.
3. Укажите левой кнопкой мыши базовую точку, относительно которой будет происходить вращение объектов.
4. Укажите угол поворота вводом значения в командную строку, либо в поле динамического ввода. Угол поворота объектов может также задаваться визуально левой кнопкой мыши.

**Дополнительные опции команды Повернуть**:

* Опция **Копировать** позволяет создавать копии выбранных объектов для поворота.
* Опция **Опорный угол** позволяет поворачивать объекты с указанного угла на новый (абсолютный) угол. В этом случае, необходимо задать значение опорного угла, либо указать две точки на чертеже. Далее задать значения нового абсолютного угла, либо также указать две точки на чертеже.

**Применимость команды:** Команда **Повернуть** применима для редактирование чертежей, объектов **ЦММ и Трасс**.
