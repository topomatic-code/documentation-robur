# Удлинение объектов

Данная функция позволяет удлинять отрезки или конечные сегменты полилиний до заданных границ других объектов.

Для этого:

1. Выберите элемент меню **Редактировать – Удлинить** или кнопку ![рис.1](_media/elongation_objects.jpg) на панели инструментов, либо введите `extend` в командную строку.
2. Укажите левой кнопкой мыши границу (объект), до которой необходимо удлинить.
3. Выберите левой кнопкой мыши удлиняемый объект.
4. Для завершения команды нажмите **Enter**.

**Применимость команды:** Команда **Удлинить** применима только для редактирования элементов чертежа.
