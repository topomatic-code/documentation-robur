# Задание атрибутов

Атрибуты могут использоваться для создания текста относящегося к блокам или группового извлечения их характеристик.

Для назначения атрибутов:

1. Выберите элемент меню **Рисовать – Блок – Задание атрибутов**, либо в командной строке введите команду `attdef`. Откроется диалоговое окно:

   ![рис.1](_media/assignment_attributes.png =688x600)

Данное окно состоит из следующих областей:

Область **Режим** содержит ряд опций, при помощи которых задаются определенные свойства атрибута:

* **Скрытый**- атрибут является невидимым на чертеже.
* **Постоянный** - атрибут имеет постоянное значение, которое может запрашиваться при вставке блока, но не может в дальнейшем быть отредактировано. Значение задается в поле Подсказка.
* **Установленный** - атрибут вставляется с установленным по умолчанию значением. В отличии от режима постоянный, данные значения доступны для редактирования.
* **Зафиксировать положение**. Блокируется положение атрибута. Если опция отключена, то атрибут можно перемещать независимо от остальных частей блока.
* **Многострочный** - многострочный атрибут.

В поле **Точка вставки** указывается положение базовой точки создаваемого атрибута на экране. При установки опции **Указать на экране**, после закрытия окна **Точка вставки**, она будет отдельно запрошена программой. Если данная опция не установлена координаты (X, Y, Z) точки вставки необходимо задать в соответствующих полях диалогового окна **Описание атрибута**.

В Поле **Атрибут** задаются следующие опции:

* **Имя** - наименование под которым атрибут будет храниться в базе данных чертежа.
* **Подсказка** - выводится при вставке блока, носит исключительно информационное значение.
* **По умолчанию** - текст отображаемый рядом с блоком на чертеже.
   
В поле **Параметры текста** задаются следующие опции:

* **Выравнивание** - атрибут может быть выровнен по ширине, центру, вправо и т.д.
* **Текстовый стиль** - выбирается из выпадающего списка. По умолчанию стоит текстовый стиль Standard.
* **Высота текста**.
* **Поворот относительно базовой точки текста**.
* **Степень растяжения** - задается масштабным коэффициентом. Если значение больше 1 происходит увеличение текста, а при меньших, уменьшение.
* **Угол наклона относительно блока**.
* Опция **Выровнять по предыдущему атрибуту** становится активной только, если создается несколько атрибутов. Выравнивание атрибута происходит относительно предыдущего.
