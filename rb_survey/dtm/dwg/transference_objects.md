# Перенос объектов

Данная команда позволяет осуществлять плоско - параллельный перенос выбранных объектов.

Для этого:

1. Выберите элемент меню **Редактировать – Перенести** или кнопку ![рис.1](_media/transference_objects.gif) на панели инструментов, либо введите `move` в командную строку.
2. Выберите левой кнопкой мыши объекты для перемещения.
3. Укажите левой кнопкой мыши базовую точку объектов.
4. Укажите левой кнопкой мыши конечное положение базовой точки на чертеже. Также, можно графически выбрать направление и задать значение перемещения в строке динамического ввода.

**Применимость команды:** Команда **Перенести** применима для редактирования чертежей ситуации, объектов **ЦММ и Трасс.**
