# Создание полилинии

**Полилиния** – это примитив, состоящий из прямых и круговых сегментов.

![рис.1](_media/create_polyline.png =688x249)

Для создания полилинии:

1. Выберите элемент меню **Рисование – Полилиния** или кнопку ![рис.2](_media/create_polyline4.png) на панели **Рисовать**, либо введите `polyline` в командную строку.
2. Укажите в рабочей области при помощи курсора начальную точку полилинии, щелкнув в соответствующем месте левой кнопкой мыши.
3. Нажмите правую кнопку мыши, откроется контекстное меню:

   ![рис.3](_media/create_polyline2.png =300x223)

   * Выберите элемент меню **Отменить** для выхода из режима ввода полилинии.
   * Выберите элемент меню **Последний ввод** для отображения списка последних вызываемых операций.
   * При выборе элемента меню **Длина** можно задать длину данного сегмента. После этого длина будет фиксирована и равна текущему значению. Направление вводимого сегмента принимается по касательной к конечной точки предыдущего.
   * При выборе элемента меню **Ширина** можно задать ширину вводимого сегмента.
   * Выберите элемент меню **Переопределение привязок** для однократного изменения текущих привязок в процессе построения.
   * При необходимости, выберите элемент **Дуга** (для построения кругового сегмента). Укажите левой кнопкой мыши в пределах рабочего поля конечную точку дуги. Либо, еще раз щелкните правой кнопкой мыши, появится контекстное меню с вариантами построения дуги:
   
      ![рис.4](_media/create_polyline3.png =300x358)
   
   * При выборе элемента меню **Угол** можно задать величину центрального угла для кругового сегмента. Для этого, введите значение угла в строке динамического ввода, а затем, укажите положение конечной точки дуги.
   * При выборе элемента меню **Центр** можно задать левой кнопкой мыши положения центра для кругового сегмента полилинии.
   * При выборе элемента меню **Направление** можно задать направление касательной в начальной точке кругового сегмента. Для этого, левой кнопкой мыши задайте направление касательной, а затем, укажите положение конечной точки дуги.
   * При выборе элемента меню **Линейный** происходит обратный переход в режим рисования прямолинейных сегментов.
   * При выборе меню **Радиус** можно задать радиус кругового сегмента. Для этого, введите значение радиуса дуги в строке динамического ввода, а затем, укажите положение конечной точки дуги.
   * Для построения кругового сегмента по трем точкам необходимо выбрать пункт меню **Вторая** (задание второй точки).
   * **Отменить последний ввод** позволяет отменить последний введенный элемент полилинии.
   * При выборе элемента меню **Ширина** можно задать ширину вводимого сегмента.
   
4. Для выхода из режима построения и подтверждения ввода нажмите **Enter**.
