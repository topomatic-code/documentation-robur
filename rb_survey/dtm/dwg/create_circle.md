# Создание окружности

Для создания окружности:

1. Выберите элемент меню **Рисовать – Круг – Центр**, радиус или кнопку ![рис.1](_media/create_circle.gif) на панели **Рисовать**, либо введите `circle` в командную строку.
2. Левой кнопкой мыши укажите положение центра круга.
3. Задайте значение радиуса окружности визуально, щелкнув левой кнопкой мыши в необходимом месте рабочего пространства, или введите его точное значение в строке динамического ввода.

После выполнения **п. 1**, также возможны альтернативные варианты построения окружности. Нажмите правую кнопку мыши, откроется контекстное меню:

![рис.2](_media/create_circle2.png =300x156)

* Выберите элемент меню **Отменить** для выхода из режима ввода окружности.
* Выберите элемент меню **Последний ввод** для отображения списка последних вызываемых операций.
* Выберите элемент меню **2 точки для построения** по двум точкам принадлежащим диаметру будущей окружности. Необходимо последовательно левой кнопкой мыши указать 1-ю и 2-ю точку диаметра окружности. Для построения окружности данным способом также можно воспользоваться элементом меню **Рисовать-Круг-2 точки**.
* Выберите элемент меню **3 точки для построения** по трем точкам принадлежащим будущему контуру окружности. Необходимо последовательно левой кнопкой мыши указать 1-ю, 2-ю и 3-ю точку окружности. Для построения окружности данным способом также можно воспользоваться элементом меню **Рисовать-Круг-2 точки**.
* Выберите элемент меню **Переопределение привязок** для однократного изменения текущих привязок.
