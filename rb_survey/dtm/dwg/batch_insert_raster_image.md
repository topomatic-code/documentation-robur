# Пакетная вставка растрового изображения

Данная функция предназначена для подгрузки в проект одновременно нескольких растровых изображений с исходными координатами.

{% note info %}

В основном в работе используют форматы растровых изображений, которые хранят в себе необходимые привязочные данные например, **\*.TIFF**, **\*.ECW**.  

 Дополнительные файлы привязки применяют для форматов растровых изображений без привязочных данных (например, **\*.JPG**). Для пакетной подгрузки, такие растровые файлы и их файлы привязки должны храниться в одной папке.

{% endnote %}

Для этого:

1. Выберите меню **Рисовать – Растровая подложка – Пакетная вставка**.
2. В открывшемся окне выберите папку с растрами и файлами привязок этих растров, которые необходимо подгрузить в проект и нажмите **ОК**.
3. При необходимости использования относительного пути, из контекстного меню, выберите пункт «*Да*».  

В результате растровые изображения подгрузятся в проект и отобразятся в рабочем окне.
