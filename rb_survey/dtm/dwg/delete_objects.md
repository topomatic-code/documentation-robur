# Удаление объектов

Для удаления объектов выполните следующие действия:

1. Выберите элемент меню **Редактировать – Удалить** или кнопку ![рис.1](_media/delete_objects.gif) на панели инструментов, либо введите `erase` в командную строку.
2. Выделите рамкой объекты для удаления.
3. Для завершения команды щелкните правую кнопку мыши.

**Применимость команды:**

Команда **Удалить** применима для редактирование чертежей, объектов **ЦММ** и **Трасс.**
