# Размерный текст

Данный инструмент позволяет менять положение размерного текста, в зависимости от выбранной функции. Для этого:

1. Выберите меню **Рисовать – Размеры – Размерный текст** – *выберите необходимую функцию*:

* **В начало** (![рис.1](_media/dimensional_text_1.jpg)) – возвращение текста в исходную позицию, если текст предварительно был перемещен вручную (с помощью грипа).
* **Угол** (![рис.2](_media/dimensional_text_2.jpg)) – поворот текста на заданный угол.
* **Слева** (![рис.3](_media/dimensional_text_3.jpg)) – перемещение текста к левой выносной линии.
* **По центру** (![рис.4](_media/dimensional_text_4.jpg)) – выравнивание текста по центру размерной линии.
* **Справа** (![](_media/dimensional_text_5.jpg)) - перемещение текста к правой выносной линии.

2. ЛКМ укажите размер, в котором необходимо поменять местоположение текста. Для подтверждения команды нажмите ПКМ или Enter.

{% note info %}

В случае выбора функции **Угол** укажите нужный размер, затем в динамическом вводе задайте угол поворота текста и нажмите **Enter**.

{% endnote %}

В результате размерный текст примет заданное положение.
