# Задание команд для редактирования объектов чертежа

Все команды группы могут вызываться следующими способами:

* Из меню **Редактировать**. Откроется контекстное меню, в котором необходимо выбрать нужную команду.
* Щелчком мыши по соответствующей кнопке на панели инструментов **Редактировать**.
* Ввод уникальной команды в командную строку. Каждой команде присваивается уникальное название.

Каждый объект обладает своим набором свойств. Данные свойства присваиваются в зависимости от формы и сложности объекта. Под свойствами объекта понимаются **общие параметры** (цвет, тип линии, слой и т.д.) и **геометрия** (уникальные характеристики объекта), у некоторых объектов существует параметр разное (указывается ширина объекта и замкнутость). Для отображения и одновременного редактирования свойств объекта можно воспользоваться основным меню программы, а также функциями быстрого ввода.

Для того чтобы открыть окно **Свойства** через основное меню программы:

1. Выберите элемент меню **Редактировать – Свойства**. Откроется окно **Свойства**.
2. Укажите объект, нажав на него левой кнопкой мыши.
3. В окне **Свойства** появятся параметры выбранного объекта.

Для того чтобы открыть окно **Свойства** с помощью функции **Быстрый ввод**:

1. Укажите левой кнопкой мыши объект или группу объектов в модели проекта.
2. Нажмите правую кнопку мыши. Откроется контекстное меню.
3. Выберите пункт меню **Свойства**. На экране в окне **Свойства** появятся параметры выбранного объекта.
