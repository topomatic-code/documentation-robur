# Измерить уклон

Данная функция позволяет измерить уклон участка поверхности между двумя указанными точками.

Для этого:

1. Сделайте текущей модель, в которой необходимо измерить уклон между точками.
2. Выберите меню **Поверхность – Анализ – Уклон** и последовательно укажите две точки, которые находятся в пределах поверхности.

В результате в динамической подсказке отобразится значение уклона между указанными точками.
