# Удалить триангуляцию внутри контура

С помощью этой функции можно удалять триангуляцию локально, внутри контура ограниченного структурной линией.

Для этого:

1. Выберите элемент меню **Поверхность - Построения – Удалить триангуляцию внутри контура**.
2. Курсор примет форму прицела, левой кнопкой мыши щелкните по ограничивающему контуру, в пределах которого необходимо удалить треугольники.
3. Для подтверждения выбора щелкните правой кнопкой мыши.

{% note info %}

Структурная линия, внутри которой производится удаление треугольников, должна иметь тип **Ограничивающая**.

{% endnote %}
