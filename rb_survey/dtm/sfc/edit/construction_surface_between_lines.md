# Перестроить между линиями

Данная функция позволяет перестроить/построить ЦММ между двумя незамкнутыми структурными линиями. Эта функция удобна когда, например, необходимо перестроить поверхность между существующей кромкой и существующей осью дороги.

Для этого:

1. Выберите меню **Поверхность – Построения – Перестроить между линиями**, курсор примет форму прицела.
2. Выберите две структурные линии, между которыми необходимо перестроить/построить поверхность.

   {% note info %}

   Структурные линии, между которыми будет производиться перестроение, должны иметь флаг **Ограничивающая**.

   {% endnote %}

В результате, построится (перестроится) поверхность между выбранными структурными линиями.

{% note info %}

Так как программа при работе функции всё равно будет выполнять условное замыкание структурных линий, то желательно, чтобы длина этих линий была примерно одинаковой, иначе при перестроении поверхности могут быть захвачены не нужные треугольники.

{% endnote %}
