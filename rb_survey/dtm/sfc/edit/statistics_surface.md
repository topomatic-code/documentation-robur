# Статистика поверхности

С помощью данной функции возможно получение сводной информации о текущей поверхности. В частности:

* Количество структурных линий.
* Площадь 2D.
* Площадь 3D.
* Количество точек.
* Количество треугольников.

Для этого выберите меню **Поверхность – Анализ – Статистика поверхности**.

В результате проанализированная программой информация отразится в командной строке.
