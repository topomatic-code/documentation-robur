# Перестроить проектную поверхность

Данная функция перестраивает проектную поверхность, например модели **Автомобильные дороги** или **Железные дороги**.

{% note info %}

При необходимости перестраивать проектную поверхность динамически после каждого изменения, задайте соответствующие настройки модели.

{% endnote %}

Для этого:

1. Сделайте текущей модель автомобильная дорога, в которой необходимо перестроить проектную поверхность.
2. Выберите меню **Поверхность – Построения - Перестроить проектную поверхность**.

После выполнения выше описанных действий запустится процесс перестроения поверхности.
