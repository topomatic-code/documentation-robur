# Добавить треугольник

Функция позволяет вручную построить элемент поверхности треугольник по выбранным рельефным точкам. К примеру, данная функция может использоваться для перестроения локального участка поверхности.

Для добавления треугольника:

1. Выберите меню **Поверхность – Построения – Добавить треугольник**, курсор примет форму прицела.
2. Последовательно укажите три рельефные точки, программа построит по ним треугольник.
