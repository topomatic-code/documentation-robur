# Credo

**{{robur}}** позволяет импортировать данные из **Credo top**-файлов (файлы съемочных точек).

Для этого :

1. Выберите элемент меню **Поверхность - Импорт/Экспорт-Импорт поверхности**, появится следующие диалоговое окно:

   ![рис.1](_media/import.jpg)

2. В поле **Формат файлов** из выпадающего списка выберите **Credo Top**-файлы.

3. Укажите импортируемый файл нажав кнопку ![рис.2](_media/import11.png =25x21). Путь к загружаемому файлу отображается в поле **Исходные файлы**.

   {% note info %}

   Все опции данного диалогового окна были описаны в предыдущем разделе ([Тектовый файл](txt.md)). Редактировать настройки импорта из **Credo Top-файла** нельзя.

   {% endnote %}

4. Нажмите **Ок**.

В результате произойдет загрузка данных, и они отобразятся в рабочем окне.
