# SDR33

Точки поверхности могут загружаться не только из произвольных текстовых файлов, но и из файлов приборов, в том числе **SDR33**, если съемка сделана в координатах.

{% note info %}

 Если файл содержит описание точек в виде измерений (стоянки, углы, расстояния и т.п.), этот файл должен быть предварительно обработан в модуле **Съемка**, а уже рассчитанные (уравненные) точки можно использовать для построения поверхности.

{% endnote %}

Для загрузки точек из файлов **SDR33** (съемка в координатах):

1. Выберите элемент меню **Поверхность - Импорт/Экспорт-Импорт поверхности**, появится следующие диалоговое окно:

   ![рис.1](_media/import.jpg)

2. В поле **Формат файлов** из выпадающего списка выберите **SDR33** в координатах.

3. Укажите импортируемый файл, нажав кнопку ![рис.2](_media/import11.png =25x21). Путь к загружаемому файлу отображается в поле **Исходные файлы**.

   {% note info %}

   1. Все опции данного диалогового окна были описаны в предыдущем разделе ([Текстовый файл](txt.md)).
   2. Редактировать настройки импорта данного формата нельзя.

   {% endnote %}

4. Нажмите **Ок**.

В результате произойдет загрузка данных, и они отобразятся в рабочем окне.
