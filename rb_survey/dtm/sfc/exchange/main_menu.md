# Основное меню

Выше были описаны примеры импорта/экспорта данных поверхности различных форматов. Данные задачи можно выполнять как через менеджер форматов, так и через основное меню программы.

Для того чтобы подгрузить данные в текущую ЦММ:

1. Выберите элемент меню **Проект - Импортировать - Поверхность**.
2. С помощью окна **Открыть** выберите тип формата файла, который необходимо загрузить и щелкните по нему дважды левой кнопкой мыши.

Для того чтобы экспортировать данные из текущей ЦММ в файл заданного формата:

1. Выберите элемент меню **Проект - Экспортировать - Поверхность**.
2. В окне **Сохранить как** задайте наименование сохраняемого файла, а также, укажите тип формата в котором данные будут экспортированы.
3. Нажмите кнопку **Сохранить**.
