# Переместить узел

При перемещении узла структурной линии изменяется его точка привязки:

![рис.1](_media/moving_nodes_structural_lines.png =688x357)

Для того, чтобы переместить узел структурной линии выполните следующие действия:

1. Выберите элемент меню **Поверхность–Структурные линии– Переместить узел**. На экране появится графический курсор в виде перекрестия.
2. Выберите структурную линию, узел которой необходимо переместить.
3. Далее при помощи левой кнопки мыши укажите исходный узел на структурной линии, который вы хотите переместить, а затем новую точку привязки для него.
4. Для выхода из этого режима щелкните правой кнопкой мыши.
