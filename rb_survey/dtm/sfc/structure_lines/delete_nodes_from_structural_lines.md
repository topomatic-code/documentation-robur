# Удалить узел

При удалении узла, структурная линия будет соединять две его соседние точки.

![рис.1](_media/delete_nodes_from_structural_lines.png =688x413)

При удалении узла точка поверхности остается без изменения. Удаляется лишь ссылка на нее в структурной линии.

Для того, чтобы удалить узел из структурной линии:

1. Выберите элемент меню **Поверхность– Структурные линии – Удалить узел** или щелкните на кнопке панели **Структурные линии**. Появится графический курсор в виде перекрестия.
2. Укажите левой кнопкой мыши структурную линию, из которой необходимо удалить узел.
3. Укажите левой кнопкой мыши узел на линии, который нужно удалить.
4. При необходимости выберите другой узел для удаления.
5. После окончания операции нажмите правую кнопку мыши.
