# Пересечь с рёбрами

Данная функция позволяет спроецировать структурную линию по всей длине на треугольники текущей поверхности.

Для этого:

1. Выберите меню **Поверхность – Структурные линии – Пересечь с рёбрами**, курсор примет форму прицела.
2. Укажите необходимую структурную линию.

В результате структурная линия будет спроецирована строго параллельно поверхности с созданными дополнительными узлами в местах пересечений с рёбрами.

{% note info %}

Данная функция применяется для **Не Ограничивающих** структурных линий.Точки, созданные на пересечениях с рёбрами будут иметь флаг **Ситуационная**.

{% endnote %}
