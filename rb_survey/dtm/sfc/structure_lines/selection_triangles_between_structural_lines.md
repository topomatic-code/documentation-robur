# Выделить треугольники между

Данная функция позволяет выделять треугольники, находящиеся между незамкнутыми структурными линиями. Этот механизм также может быть полезен для включения их в заданную группу.

Для этого:

1. Выберите элемент меню **Поверхность - Структурные линии - Выделить треугольники между**.
2. Курсор примет форму прицела, выберите левой кнопкой мыши структурные линии.
3. Щелкните правой кнопкой мыши для подтверждения выбора.

{% note info %}

После выбора группы ребер, с ними можно произвести различные операции (удаление, редактирование, назначение семантической информации отвечающей за их отображение и т.п.).

{% endnote %}
