# Выделить треугольники внутри

Данная функция позволяет выделять треугольники внутри контура ограниченного структурной линией. Этот механизм может быть полезен для включения их в заданную группу.

Для этого:

1. Выберите элемент меню **Поверхность - Структурные линии - Выделить треугольники внутри**.
2. Курсор примет форму прицела, щелкните по структурной линии левой кнопкой мыши.
3. Щелкните правой кнопкой мыши для подтверждения выбора.

{% note info %}

 После выбора группы ребер, с ними можно произвести различные операции (удаление, редактирование, назначение семантической информации отвечающей за их отображение и т.п.).

{% endnote %}
