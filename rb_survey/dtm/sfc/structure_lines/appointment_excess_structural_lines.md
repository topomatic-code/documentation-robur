# Спроецировать на поверхность

Функция позволяет задать превышение узлов структурной линии относительно текущей поверхности. Эта процедура может быть полезна при назначении коммуникаций из неограничивающих структурных линий. В случае, когда точные отметки узлов коммуникации изначально не известны, их можно вычислять приблизительно, т.е. по превышению/залеганию относительно поверхности земли.

Для этого:

1. Выберите элемент меню **Поверхность - Структурные линии – Спроецировать на поверхность**.
2. Курсор примет форму прицела, выберите левой кнопкой мыши необходимую структурную линию.
3. В строке динамического ввода задайте превышение. При задании отрицательного значения, структурная линия будет расположена под текущей поверхностью.
4. Для выхода из текущего режима щелкните правой кнопкой мыши.

В результате, всем узлам структурной линии будет присвоена высота вычисленная относительно **ЦММ**. При отсутствии поверхности превышение будет вычисляться относительно нулевого уровня.
