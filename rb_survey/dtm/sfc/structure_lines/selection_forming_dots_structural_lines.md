# Выделить образующие точки

Данная функция позволяет выделять группу точек входящих в структурную линию.

Для этого:

1. Выберите элемент меню **Поверхность - Структурные линии - Выделить образующие точки**.
2. Курсор примет форму прицела, щелкните по структурной линии левой кнопкой мыши.
3. Щелкните правой кнопкой мыши для подтверждения выбора.

{% note info %}

После выбора группы узлообразующих точек, с ними можно произвести различные операции (удаление, редактирование, назначение семантической информации отвечающей за их отображение и т.п.).

{% endnote %}
