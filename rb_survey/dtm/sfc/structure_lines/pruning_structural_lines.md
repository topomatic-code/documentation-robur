# Обрезать

Данная функция позволяет обрезать структурную линию до границы пересечения с исходной структурной линией.

Для этого:

1. Выберите меню **Поверхность – Структурные линии – Обрезать**, курсор примет форму прицела.
2. Укажите структурную линию (исходную), до которой необходимо обрезать.
3. Выберите обрезаемую линию с той стороны от секущей границы, которая должна быть удалена.

В результате, обрезаемая часть структурной линии удалится и в месте пересечений структурных линий добавится узел с отметкой, которая вычисляется путём интерполяции, между отметками соседних узлов обрезаемой структурной линии.

{% note info %}

Если структурная линия, до которой необходимо обрезать, не является ограничивающей, то добавленная точка на пересечении линий будет иметь флаг **Ситуационная**.

{% endnote %}
