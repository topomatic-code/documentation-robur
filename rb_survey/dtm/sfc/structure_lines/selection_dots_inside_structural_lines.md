# Выделить точки внутри

Контур структурной линии может использоваться для выделения точек находящихся внутри его.

Для того, чтобы выделить точки внутри структурной линии:

1. Выберите элемент меню **Поверхность - Структурные линии - Выделить точки внутри**.
2. Курсор примет форму прицела, щелкните по структурной линии левой кнопкой мыши.
3. Щелкните правой кнопкой мыши для подтверждения выбора.

{% note info %}

После выбора группы точек, с ними можно произвести различные операции (удаление, редактирование, назначение семантической информации отвечающей за их отображение и т.п.).

{% endnote %}
