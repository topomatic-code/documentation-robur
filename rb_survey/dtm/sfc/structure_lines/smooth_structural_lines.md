# Сгладить

Функция позволяет сгладить отрисованную структурную линию сплайном.

Для этого:

1. Выберите меню **Поверхность – Структурные линии – Сгладить**, курсор примет форму прицела.
2. Укажите структурную линию. В результате структурная линия будет сглажена путем добавления определенного количества узлов, которые по умолчанию будут находиться на слое **Дополнительные отметки**.

{% note info %}

Интерполяция отметок будет производиться по уравнению кривой сплайна.

{% endnote %}
