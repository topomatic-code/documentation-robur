# Объединить

С помощью этой функции можно объединить две структурные линии, если они имеют общую конечную точку. При объединении двух линий в одну, свойства результирующей линии (полученной в результате объединения) будут приниматься по исходной (первой выбранной).

Для этого необходимо выполнить следующие действия:

1. Выберите элемент меню **Поверхность – Структурные линии – Объединить**.
2. На экране появится курсор в виде перекрестия, укажите первую линию, щелкнув по ней левой кнопки мыши.
3. Укажите вторую линию, которая должна быть пристыкована к первой.
4. Для выхода из этого режима нажмите правую кнопку мыши.
