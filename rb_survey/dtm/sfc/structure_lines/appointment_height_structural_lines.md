# Задать отметку точкам

Данная функция позволяет назначить всем узлам и точкам, входящим в структурную линию определенный уровень. Эта процедура может быть полезна при построении поверхности по растровой подложке, когда структурные линии вводятся по горизонталям карты и в последствии им должна быть назначена соответствующая высота.

Для этого:

1. Выберите элемент меню **Поверхность - Структурные линии – Задать отметку точкам**, курсор примет форму прицела.
2. Укажите левой кнопкой мыши структурную линию, которой необходимо присвоить уровень.
3. В строке динамического ввода задайте ей требуемую высоту.
4. Для выхода из текущего режима щелкните правой кнопкой мыши.

В результате всем узлам и точкам, входящим в структурную линию будет присвоена соответствующая высота.
