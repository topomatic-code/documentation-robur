# Выделить точки между

Контуры незамкнутых структурных линий также могут использоваться для выделения точек находящихся между ними.

Для этого:

1. Выберите элемент меню **Поверхность - Структурные линии - Выделить точки между**.
2. Курсор примет форму прицела, выберите структурные линии левой кнопкой мыши.
3. Щелкните правой кнопкой мыши для подтверждения выбора.

{% note info %}

После выбора группы точек, с ними можно произвести различные операции (удаление, редактирование, назначение семантической информации отвечающей за их отображение и т.п.).

{% endnote %}
