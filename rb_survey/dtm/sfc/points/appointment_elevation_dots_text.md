# Копировать отметку с текста

Данная функция позволяет с примитива однострочный текст, присвоить высотное положение (отметка Z) точкам поверхности. Например, это используется в случае, когда при импорте поверхности из dxf - файла у примитива точек высотное положение Z равняется нулю и подписи отметок определяются как примитив Текст.

Для этого:

1. Импортируйте необходимую поверхность.

   {% note info %}

   Описание импорта поверхности представлено в разделе [Импорт/экспорт данных для построения ЦММ](../exchange/dxf.md).

   {% endnote %}

2. Подгрузите необходимую ситуацию с подписями отметок поверхности (с текстовыми примитивами).

   {% note info %}

   Описание импорта ситуации представлено в разделе [Внешний редактор. Быстрый импорт/экспорт ситуации](../../dwg/quick_import_export_situation.md).

   {% endnote %}

3. Выберите в меню **Поверхность – Точки – Копировать отметку с текста**, курсор примет форму прицела.

4. Выберите текст, который будет присвоен высотному положению точкам поверхности, одним из представленных способов:

* Выберите непосредственно текст отметки, далее укажите необходимую точку поверхности.

  В результате, содержимое текста примитива будет присвоено высоте точки поверхности.

* Или нажмите правой кнопкой мыши и из контекстного меню выберите **Автоматически**, затем в строке динамического ввода укажите **Радиус поиска** точки относительно текста, далее нажмите правой кнопкой мыши или **ENTER**.

В результате относительно каждого текста будет найдена ближайшая точка поверхности, высотное положение которой будет соответствовать содержанию этого текста.
