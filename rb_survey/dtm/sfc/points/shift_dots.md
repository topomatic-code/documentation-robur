# Сдвинуть точки на примитив

Данная команда позволяет изменить плановое положение съемочных точек, сдвинув их на заданный примитив.

Для этого необходимо выполнить следующие действия:

1. Выберите элемент меню **Поверхность – Точки – Сдвинуть точки на примитив**.
2. Выберите точки, которые необходимо сдвинуть на примитив. По окончанию выбора нажмите правую клавишу мыши.
3. Укажите левой кнопкой примитив.

   Все выбранные точки по перпендикуляру сдвинутся на указанный примитив.

4. Если необходимо, повторите шаги 2-3.
5. Нажмите клавишу **ENTER** для завершения команды.

{% note info %}

 При выполнении данной команды произойдет автоматическое перестроение поверхности с учетом нового планового положения точек.

{% endnote %}
