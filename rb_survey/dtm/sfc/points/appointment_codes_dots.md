# Назначить код по структурной линии

Данная команда предназначена для быстрой перекодировки точек принадлежащих структурной линии.

Чтобы назначить коды точек по коду структурной линии:

1. Выберите элемент меню **Поверхность – Точки – Назначить код по структурной линии**.

2. Выберите левой кнопкой мыши одну или несколько структурных линий. По окончании выбора нажмите правую клавишу мыши.

   Все точки принадлежащие выбранным структурным линиям будут перекодированы в соответствии с кодами этих структурных линий.

3. Если необходимо, повторите шаг 2.

4. Нажмите клавишу **ENTER** для завершения команды.
