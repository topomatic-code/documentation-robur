# На линии/кривой

Данная команда предназначена для создания точек на концах линии, полилинии, или дуги.

Чтобы создать точки на линии или кривой:

1. Выберите элемент меню **Поверхность – Точки - Разметить – На линии/кривой**.
2. Выберите левой кнопкой мыши линию, полилинию или дугу.
3. Для каждой создаваемой точки откроется окно **Свойства точки поверхности**, в котором можно ввести ее наименование, описание и всю необходимую семантическую информацию.
4. В конечных точках объекта будут созданы точки поверхности.
5. Если необходимо, повторите шаги 2 и 3.
6. Нажмите клавишу **ENTER** для завершения команды.

{% note info %}

 Если выбранный объект расположен вне **ЦММ**, отметка Z каждой точки по умолчанию принимается равной отметке вершины полилинии.

{% endnote %}
