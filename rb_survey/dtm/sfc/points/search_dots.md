# Искать по номеру

Данная функция осуществляет поиск точки с заданным номером среди группы других и отображает ее на экране. Для этого:

1. Выберите меню **Поверхность – Точки – Искать по номеру**.
2. В строке динамического ввода введите номер искомой точки и нажмите **Enter**.

В результате, точка с заданным номером будет подсвечена и отображена в центре графического поля программы.
