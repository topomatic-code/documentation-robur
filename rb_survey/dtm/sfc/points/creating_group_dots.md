# Разделить объект

Данная функция позволяет создать определенное количество равномерно расположенных точек вдоль линии, полилинии или дуги. Точки могут быть размещены на объекте или смещены от него.

При создании точек с помощью этой команды всегда работа идет только с одним объектом. Если при использовании данной команды, выбранные объекты и указанные опции приведут к созданию повторяющихся (дублирующихся) точек, например на общем конце двух линий, то программа выдаст предупреждающее сообщение о создании дублирующихся точек.

Чтобы создать заданное количество точек вдоль объекта путем его деления:

1. Выберите элемент меню **Поверхность – Точки - Разметить – Разделить объект**.

2. Выберите левой кнопкой мыши линию, полилинию или дугу.

3. Введите количество сегментов, на которое будет разделен объект.

4. При необходимости задать точки со смещением относительно объекта, введите значение смещения.

5. Откроется окно **Свойства точки поверхности**, в котором можно ввести ее имя, описание точки и всю необходимую семантическую информацию. Эти параметры будут применены для всех введенных точек.

Вдоль объекта на указанном смещении от него будет размещена серия точек, расположенных на равных расстояниях друг от друга.

6. Если необходимо, повторите шаги 2-5.

7. Нажмите клавишу **ENTER** для завершения команды.

{% note info %}

 Если выбранный объект расположен вне ЦММ, отметка Z каждой точки вычисляется интерполяцией отметок между вершинами полилинии.

{% endnote %}
