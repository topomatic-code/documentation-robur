# Подписать горизонтали автоматически

Данная функция позволяет автоматически проставить подписи по выбранным горизонталям.

Для этого:

1. Выберите меню **Поверхность – Горизонтали – Подписать горизонтали автоматически**.
2. С помощью курсора в виде прицела выберите горизонтали или с помощью секущей рамки укажите область с горизонталями, которые необходимо подписать, далее нажмите правой кнопкой мыши или **ENTER**.
3. В строке динамического ввода укажите шаг подписей по горизонталям (интервал между подписями) и нажмите правой кнопкой мыши, далее выберите один из вариантов подписи горизонталей:

* Пункт **Да** предназначен для подписи только утолщенных горизонталей.
* Пункт **Нет** предназначен для подписи всех горизонталей.

В результате выбранные горизонтали будут подписаны в качестве многострочного текста.
