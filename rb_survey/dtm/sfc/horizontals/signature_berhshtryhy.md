# Подписать бергштрихи

Данная команда позволяет подписать бергштрихи по линии.

Для этого:

1. Выберите элемент меню **Поверхность – Горизонтали – Подписать бергштрихи**:
   
   ![рис.1](_media/signature_horizontals.jpg)
   
2. Выберите один из вариантов нанесения бергштрихов. Выберите **Да** - для нанесения бергштрихов только на утолщенных горизонталях, **Нет** – для нанесения бергштрихов на все горизонтали.
3. Последовательно указав две точки, задайте линию, в местах пересечения которой с горизонталями будут рисоваться бергштрихи.
4. Если необходимо, повторите шаги 2 и 3.
5. Нажмите клавишу **ENTER** для завершения команды.
