# Добавить треугольники

В процессе редактирования ЦММ может возникнуть необходимость добавить треугольники к уже предварительно созданному участку.

Для этого:

1. Выберите элемент меню **Поверхность – Участки – Добавить треугольники**.
2. Курсор примет форму прицела, укажите вначале участок, к которому необходимо добавить треугольники, щелкнув по нему левой кнопкой мыши, а затем последовательно выберите сами недостающие треугольники.
3. Для подтверждения выбора щелкните правой кнопкой мыши.

Дополнительные треугольники будут включены в участок и автоматически примут соответствующие ей свойства (семантическая информация, параметры отображения и т.п.).
