# Разбить

Данная функция по своему смыслу противоположна предыдущей. Она позволяет разбить треугольники образующие участок на отдельные исходные составляющие.

Для этого:

1. Выберите элемент меню **Поверхность – Участки – Разбить**.
2. Курсор примет форму прицела, укажите необходимую область треугольников образующих участок.
3. Для подтверждения выбора щелкните правой кнопкой мыши.

В результате, участок будет разбит на исходные объекты.
