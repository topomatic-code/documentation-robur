# Объединить

Для удобства редактирования или получения сводной информации о характеристиках объекта (например: общая площадь), несколько участков с одинаковыми свойствами, можно объединять в один.

Для этого:

1. Выберите элемент меню **Поверхность – Участки – Объединить**.
2. Курсор примет форму прицела, последовательно укажите участки, которые требуется объединить, щелкая по ним левой кнопкой мыши.
3. Для подтверждения выбора щелкните правой кнопкой мыши.

В результате, несколько участков будет объединено в один.

{% note info %}

Если объединяемые участки обладают разными свойствами, то свойства результирующего участка будут соответствовать первому из указанных в процессе выбора.

{% endnote %}
