# Создать

Для того чтобы из набора треугольников сформировать участков:

1. Выберите элемент меню **Поверхность - Участки - Создать**, курсор примет форму прицела.

2. Укажите набор треугольников, на основе которых надо создать участок.

Это можно сделать следующими способами:

* Удерживая клавишу **Shift**, последовательно выберите необходимые треугольники, щелкая по ним левой кнопкой мыши.
* Удерживая клавишу **Ctrl** с помощью секущей рамки выберите область треугольников, по которым будет создан участок.

   {% note info %}

   Если в процессе выбора случайно были указаны лишние треугольники, их можно исключить из участка до его создания. Для этого удерживая клавишу **Shift** повторно нажмите на ненужный треугольник.

   {% endnote %}

3. Для подтверждения выбора щелкните правой кнопкой мыши.

На основе выбранных треугольников будет создан участок. При дальнейшем выборе какого-либо треугольника из участка, будут выделяться все треугольники образующие его.
