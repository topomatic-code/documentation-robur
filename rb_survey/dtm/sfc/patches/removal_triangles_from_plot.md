# Удалить треугольники

Данная функция позволяет убрать из участка отдельные треугольники, не удаляя при этом его самого.

Для этого:

1. Выберите элемент меню **Поверхность – Участки – Удалить треугольники**.
2. Курсор примет форму прицела, последовательно укажите треугольники, которые необходимо исключить, щелкая по ним левой кнопкой мыши.
3. Для подтверждения выбора щелкните правой кнопкой мыши.

Выбранные треугольники будут исключены из участка, которому они принадлежали.
