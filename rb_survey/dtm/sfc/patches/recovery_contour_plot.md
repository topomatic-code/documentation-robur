# Восстановить контур

Данная функция позволяет автоматически создать замкнутую структурную линию, являющуюся контуром соответствующего участка. В последствии, этот контур может быть использован для различных задач. Например: перестроения поверхности внутри замкнутой структурной линии или отображения его определенным условным знаком.

Для этого:

1. Выберите элемент меню **Поверхность – Участки – Восстановить контур**.
2. Курсор примет форму прицела, последовательно укажите левой кнопкой мыши участки, для которых надо создать контурные структурные линии.
3. Для подтверждения выбора щелкните правой кнопкой мыши.

В результате, вокруг каждого указанного участка будет сформирована ограничивающая структурная линия. Для редактирования свойств данного контура используются стандартные инструменты редактирования структурных линий.
