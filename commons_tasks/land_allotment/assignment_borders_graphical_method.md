# Задание границ проектного, временного и существующего землеотвода графическим способом

Границы проектного, временного и существующего землеотвода могут быть назначены из примитивов, предварительно отрисованных на плане.

К примеру, для того чтобы назначить левую границу временного отвода:

1. Выберите элемент меню **Задачи - Отвод земель - Задать временный землеотвод по ситуации - Левый**.
2. Курсор примет форму прицела. Укажите левой кнопкой мыши исходный примитив.

В результате, программа создаст границу отвода на основе выбранного линейного объекта.
