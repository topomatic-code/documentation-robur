- ГОСТ Р 71404-2024 {#gost-71404-2024}

  ![рис.1](_media\road_tasks_71404.png)

  В данном окне, задаются дополнительные настройки расчета дорожной одежды.

  {% cut "**Отображать дополнительные предупреждения**" %}{#71404-2024-preduprezhdeniya}

  Программа контролирует следующие требования:

  * Соответствие типа дорожных одежд виду покрытия (**ГОСТ Р 71404-2024, п.6.11 и п.6.12**);
  * Соответствие заданного уровня надежности типу дорожной одежды и категории дороги (**ГОСТ Р 71404-2024, табл. 5**);
  * Соответствие типа дорожных одежд категории дороги (**ГОСТ Р 71404-2024, табл. 5**);
  * Соответствие нагрузки типу дорожной одежды (**ГОСТ Р 71404-2024, п. 7.1.1, 7.1.2**);
  * Соответствие минимальной толщины слоя дорожной одежды (**ГОСТ Р 71404-2024, п. 6.4**);
  * Соответствие общей толщины слоев основания (**ГОСТ Р 71404-2024, п. 6.4**);
  * Наличие слоя износа (**ГОСТ Р 71404-2024, п. 6.5**);
  * Соответствие общего модуля на поверхности рабочего слоя (**ГОСТ Р 71404-2024, п. 6.13.1**);
  * Необходимые критерии расчета для облегченного типа дорожной одежды (**ГОСТ Р 71404-2024, п. 9.1.3**);
  * Необходимость корректировки свойств слоев из асфальтобетона при различных вариантах конструкции **(ГОСТ Р 71404-2024, примечания к табл. Г.4 и Г.5)**.

  {% endcut %}

  {% cut "**Контакт между покрытием и основанием**" %}{#71404-2024-kontakt-pokrytie-osnovanie}

  Данная настройка отвечает за определение растягивающего напряжения при изгибе в асфальтобетоне от единичной нагрузки $\bar{\sigma_r}$ при давлении на покрытие $p$ = 1 МПа.

  По умолчанию используется автоматическое определение, согласно п. 9.5.3 **ГОСТ Р 71404-2024**, в зависимости от типа материала.

  * Спаянный контакт (см. рисунок Е.51) между слоями из асфальтобетона, а также между слоем из асфальтобетона и монолитным слоем основания, содержащим органическое вяжущее (включая материалы по ГОСТ Р 70197.1).
  * Гладкий контакт (см. рисунок Е.52) следует принимать между нижним слоем из асфальтобетона и слоем основания дорожной одежды под ним из неукрепленных материалов, а также между слоем из асфальтобетона и монолитным слоем основания, не содержащим органическое вяжущее.

  Для расчета усиления необходимо вручную выбирать номограмму для определения растягивающего напряжения при изгибе в асфальтобетоне от единичной нагрузки $\bar{\sigma_r}$ при давлении на покрытие $p$ = 1 МПа.

  {% endcut %}

  {% cut "**Использовать значения коэффициентов с учетом комментариев от разработчиков**" %}{#1006-2025-koeff-rascheta}

  В программе предусмотрена возможность учитывать следующие корректировки алгоритма подбора коэффициентов:

  {% list tabs accordion %}

  - Коэффициент Kmz

    Коэффициент, учитывающий увеличение отрицательных изгибающих моментов при краевом нагружении плиты за счет возможного наличия зазоров между плитой и основанием. Используется для определения суммарного нормального растягивающего напряжения, возникающего в сборном покрытии от отрицательного изгибающего момента $σ_{pt}^{(-)}$  (формула 24). По умолчанию значения принимаются по графикам на рисунке 10, ПНСТ 1006:

    ![Общий модуль упругости](_media\koeff-rascheta_1.png){width=539 height=325}

    Активация данной опции позволяет использовать следующий график:

    ![График](_media\koeff-rascheta_2.png){width=539 height=325}

  - Коэффициент Kx

    Коэффициент, учитывающий ортотропность одноосно обжатой плиты ПАГ или 1ПДН. Используется для определения суммарного нормального растягивающего напряжения, возникающего в сборном покрытии от положительного изгибающего момента $σ_{pt}^{(+)}$  (формула 23). По умолчанию принимаются следующие значения:
    - 1,38 для ПАГ-14, ПАГ-18, 1ПДН-14, 1ПДН-18;
    - 1,29 для ПАГ-20. 

    Активация данной опции позволяет использовать следующие значения для плит:
    - 1,38 для ПАГ-14, ПАГ-18;
    - 1,45 для 1ПДН-14, 1ПДН-18;
    - 1,29 для ПАГ-20.
    
  - Коэффициент k'

    Коэффициент, учитывающий увеличение отрицательных изгибающих моментов вследствие веса и особенностей работы плиты при краевом нагружении плиты. Используется для определения предельного значения сопротивления покрытия $R^{(-)}$  (формула 27). По умолчанию принимаются следующие значения:
    - 1,24 для ПАГ-14 и 1ПДН-14;
    - 1,26 для ПАГ-18 и 1ПДН-18;
    - 1,32 для ПАГ-20.

    Активация данной опции позволяет использовать следующие значения для плит:
    - 1,24 для ПАГ-14;
    - 1,20 для 1ПДН-14 и 1ПДН-18;
    - 1,26 для ПАГ-18;
    - 1,32 для ПАГ-20.

- ОДН 218.046-01, МР {#odn-218-046-01}

  ![рис.1](_media\road_tasks_218-046.png)

  В данном окне, задаются дополнительные настройки расчета дорожной одежды.

  {% cut "**Использовать рекомендации МОДН 2-2021**" %}{#218-046-01-modn-recomendacii}

  При установлении данной опции некоторые расчетные коэффициенты и формулы принимаются согласно **МОДН 2-2001**.

  В частности, **МОДН 2-2001** принимается:

  * Формула расчета предельного активного напряжения сдвига (формула 3.14);

  $$T_{np}=\mathit kd(с_N+0,1\gamma_{cр}z_{оn}tg\phi_{СТ}),$$

  * Значения коэффициентов, учитывающих особенности работы конструкции на границе песчаного слоя с нижним слоем несущего основания (п. 3.35);

  Коэффициент $k_д$ следует принимать равный:

  * 4,5 - для песка крупного;
  * 4,0 - средней крупности;
  * 3,0 - мелкого;
  * $k_д$ = 2 - при устройстве нижнего слоя несущего основания из неукрепленных материалов и без разделительной прослойки;
  * $k_д$ = 1 - для подстилающего дорожную одежду глинистого грунта земляного полотна.

  * Коэффициент, учитывающий снижение притока воды, при расчете на осушение и при принятии специальных мер по регулированию водно-теплового режима (табл 5.5).
