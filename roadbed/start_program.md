# Запуск программы

Запустите программу **Топоматик Robur - Дорожная одежда**, щелкнув дважды левой кнопкой мыши по соответствующему ярлыку на рабочем столе

При запуске программы открывается окно стартовой страницы:

![](_media\start1.png)

В данном окне можно создать новый расчет, открыть один из уже ранее созданных, а также импортировать расчет, выполненный в предыдущей версии программы (начиная с версии 4.3 и ранее):

## Создание нового расчета

Для того, чтобы создать новый расчет дорожной конструкции,необходимо в верхней части окна выбрать расчетную методику (тип расчета) из списка. В результате откроется основное окно программы.

![](_media\start2.png)

{% note info %}

1. Создание нового расчета, а также последовательность заполнения вкладок с данными основного окна программы и выполнения расчета будет описана описана далее в разделе **Порядок расчета**.
2. В зависимости от выбранного типа расчета может использоваться своя расчетная методика. Набор исходных данных, необходимых для его выполнения, также может отличаться.

{% endnote %}

## Открыть расчет

В средней части окна, в области **Последние расчеты**, отображается список расчетов, которые были сохранены в программе ранее. Расчет можно открыть, выбрав его из списка, для этого щелкните левой кнопкой мыши по его наименованию. В результате откроется основное окно программы с данными, которые были введены ранее.

Для открытия ранее созданного расчета, наименование которого отсутствует в списке **Последние расчеты**, выберите команду **Открыть другой расчет**. В открывшемся окне Проводника Windows укажите путь, по которому лежит файл расчета с расширением *.rbdx. В результате также откроется основное окно программы с данными по выбранному расчету.

![](_media\start3.png)

{% note info %}

Ранее созданные расчеты также можно открыть, находясь в основном окне программы, для этого выберите меню Файл - Открыть.

{% endnote %}

## Импорт расчета, созданного в предыдущей версии

Для открытия расчета, созданного в предыдущей версии программы (версия 4.3 и ранее), выберите команду **Импортировать расчет**.

![](_media\start4.png)

В открывшемся окне Проводника Windows укажите путь, по которому лежит файл расчета с расширением *.rbdx или *.lrf (расширения файлов расчета предыдущих версий программы, ранее версии 5.0). В результате откроется основное окно программы с данными, которые были получены путем импорта из старого расчета.

{% note info %}

Можно импортировать расчеты, созданные в предыдущих версиях, находясь в основном окне программы, для этого выберите меню Файл - Импортировать.

{% endnote %}
