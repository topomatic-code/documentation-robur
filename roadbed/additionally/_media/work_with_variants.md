# Работа с вариантами

По умолчанию, расчет содержит один вариант конструкции дорожной одежды: 

![](_media/work_with_variants2.jpg)

При необходимости, для сравнения результатов расчета, можно добавлять дополнительные варианты конструкций, с другими параметрами конструктивных слоев.

{% note info %}

Расчет может содержать несколько вариантов. Варианты могут отличаться именно типами конструктивных слоев дорожной одежды, характеристики задаваемые на вкладках [Общие данные](../choice_calculation/general_information.md?tabs=general-information_gost-71404-2024), [Нагрузки](../choice_calculation/loads.md?tabs=loads_gost-71404-2024) и [Осушение](../choice_calculation/draining.md?tabs=draining_gost-71404-2024) едины для расчета и всех вариантов, которые он содержит.

{% endnote %}


## Создание нового варианта

Для того чтобы создать новый вариант конструкции воспользуйтесь одним из следующих способов:

* Нажмите соответствующую кнопку, расположенную рядом с наименованием текущего варианта:

![рис.2](_media/add.jpg)

* Щелкните правой кнопкой мыши по вкладке с наименованием текущего варианта и выберите из появившегося контекстного меню пункт **Новый**:

![рис.3](_media/new_variant.jpg)

В результате будет создана дополнительная вкладка с наименованием нового варианта, который по умолчанию станет текущим: 

![рис.4](_media/additional_tab_variant.jpg)

Созданный новый вариант содержит всю информацию, которая была ранее заполнена на вкладках [Общие данные](../choice_calculation/general_information.md?tabs=general-information_gost-71404-2024) и [Нагрузки](../choice_calculation/loads.md?tabs=loads_gost-71404-2024). Вкладка **Конструкция** при создании нового варианта будет не заполнена. Все конструктивные слои в новом варианте дорожной одежды задаются и редактируются с помощью функционала, который описан ранее (см. раздел [Конструкция](../choice_calculation/construction.md?tabs=construction_gost-71404-2024)).

При необходимости создания нового варианта с конструктивными слоями дорожной одежды, на основе исходного варианта, воспользуйтесь функцией **Копировать**.

## Копирование варианта

Для того чтобы скопировать все данные, включая параметры конструктивных слоев из одного варианта в другой, щелкните правой кнопкой мыши по вкладке с наименованием исходного варианта и выберите из появившегося контекстного меню пункт **Копировать**: 

![рис.5](_media/copy_variants.jpg)

В результате будет создана дополнительная вкладка с наименованием скопированного варианта, который по умолчанию станет текущим: 

![рис.6](_media/additional_tab_variant_2.jpg)

Далее, при необходимости измените в скопированном варианте параметры конструктивных слоев (тип слоя, толщина и т.п.), используя для этого функционал описанный ранее(см. раздел [Конструкция](../choice_calculation/construction.md?tabs=construction_gost-71404-2024)).

## Переименование варианта

При создании нового варианта или его копировании он получает название по умолчанию. Для изменения названия варианта, щелкните правой кнопкой мыши по вкладке с его наименованием и выберите из появившегося контекстного меню пункт **Переименовать**: 

![рис.7](_media/rename_variants.jpg)

Задайте варианту требуемое наименование. Для подтверждения изменений щелкните правой кнопкой мыши.

## Удаление варианта

Для удаления какого-либо варианта конструкции из расчета, щелкните правой кнопкой мыши по вкладке с его наименованием и выберите из появившегося контекстного меню пункт **Удалить**: 

![рис.8](_media/delete_variants.jpg)

## Смена текущего варианта

Наименование варианта, который является в расчете текущим, подписывается жирным шрифтом. Для того чтобы переключиться на работу с другим вариантом щелкните левой кнопкой мыши по вкладке с его наименованием, данный вариант станет текущим.
