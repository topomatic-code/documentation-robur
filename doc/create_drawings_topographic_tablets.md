# Создание чертежей топографических планшетов

Программа позволяет формировать чертежи листов различных форматов и топографических планшетов, предварительно нанесенных на ситуационный план.

Последовательность действий по раскладке и формированию топографических планшетов была описана в разделе [Оформление топографического плана](../../ru/rb_survey/dtm/planchet/topographic_plan/formation_tablets.md#dobavlenie-topograficheskogo-plansheta).
