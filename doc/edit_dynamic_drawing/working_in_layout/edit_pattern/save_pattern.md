# Сохранение пользовательского шаблона

Для сохранения отредактированного шаблона в *пользовательский шаблон*:

1. На панели инструментов нажмите кнопку ![рис.1](_media/save_pattern_1.png) (**Сохранить шаблон макета**).
2. В открывшемся окне укажите место хранения и имя файла шаблона.
