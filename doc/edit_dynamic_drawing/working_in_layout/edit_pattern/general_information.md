# Общие сведения

Каждый чертеж в программе создается на основе какого-либо шаблона чертежа. Для каждого типа чертежа (*Профиль*, *Поперечник*, *Колонок выработок* и т.д.) в программе предусмотрен набор стандартных шаблонов (системные шаблоны), где по умолчанию уже настроен боковик таблицы и заданы определенные настройки отображения данных (текстовый стиль, слой, цвет и т.д.).

{% note info %}

Системные шаблоны хранятся в каталоге `C:\ProgramData\Topomatic\*наименование программы\*16.0\Plt\*Crs` - для чертежей поперечного профиля, `Prf` - для чертежей продольного профиля, `Glg` – для чертежей инженерно – геологических колонок\* каталог с шаблонами.

{% endnote %}

В режиме редактирования шаблона можно настроить набор данных и их вид, а именно добавить или удалить данные (отметки, уклоны и т.д.), настроить для них текстовый стиль, цвет, слой, тип и толщину линий и т.д. Все настроенные параметры можно сохранить в качестве отдельного пользовательского шаблона, который можно применять в дальнейшем для формирования чертежей.

В данной главе описывается структура шаблона, набор и редактирование его данных, а также сохранение шаблона в качестве *пользовательского*.

{% note info %}

В данной главе механизмы работы с шаблоном показываются на примере чертежа *Поперечные профили*, при этом описанные в данной главе механизмы являются общими и используются для работы с шаблонами также и другого типа чертежей, например, *Профиля*, *Колонок выработок* и *т.д*.

{% endnote %}
