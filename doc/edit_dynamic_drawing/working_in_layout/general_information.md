# Общие сведения

В данном разделе описываются механизмы работы в пространстве **Макет** в двух режимах - **Редактирование макета** и **Редактирование шаблона**. А именно показан инструментарий для работы и редактирования элементов макета, описан шаблон динамического чертежа и его настройка, а так же показан пример редактирования шаблона и его сохранение как пользовательского. Кроме того описаны дополнительные опции при работе в пространстве Макет.

{% note info %}

Здесь и далее описание функционала будет производиться на примере динамического чертежа поперечного профиля . Функционал для работы с динамическими чертежами *Продольного профиля*, *Колонок выработок* и *др*. идентичен.

{% endnote %}
