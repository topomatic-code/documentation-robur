# Создание участка контура

Данная команда создает новый контур из уже существующего контура. После вызова команды необходимо выбрать сначала один узел существующего контура, а потом второй. В результате будет создан новый контур, а эти узлы будут его граничными точками. Параметры вновь созданного контура также можно изменить в стандартном окне **Свойства**.
