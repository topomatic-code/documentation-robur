# Снятие растительного слоя

Наличие данного элемента конструкции позволяет производить поправку при построении контуров насыпи и выемки.

В случаях, когда создаются собственные шаблоны поперечных профилей, не на основе стандартных, элемент конструкции **Снятие растительного слоя** будет отсутствовать и при необходимости его можно добавить самостоятельно в общее дерево элементов.

Для добавления данного элемента щелкните дважды левой кнопкой мыши по его наименованию в окне **Палитра конструкции**. В результате данный элемент отобразится в списке окна **Дерево элементов конструкции**. В этом списке данный элемент должен располагаться в самом верху.

Все параметры снятия растительного слоя задаются в таблице поправок (**Поперечник - Поправки - Снятие растительного слоя**). Последовательность действий по заданию поправок к объемам земляных работ была описана ранее в соответствующем [разделе](../amendments_to_volume_work/removal_topsoil.md).
