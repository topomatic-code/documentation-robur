# Уступы. Уступ вверх, Уступ вниз

При вставке конструкции **Уступ** необходимо указать контур, относительно которого будет создан данный элемент.

{% note info %}

1. В зависимости от направления уклона указанного контура, элемент Уступ будет развернут автоматически.
2. Конструкция Уступ вверх строится исходя из параметра Ширина полки, а конструкция Уступ вниз определяется параметром Высота уступа.

{% endnote %}

* 5 - Уклон полки.
