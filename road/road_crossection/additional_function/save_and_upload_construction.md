# Сохранение и загрузка конструкции поперечного профиля

Данные текущего предварительно созданного поперечного профиля могут быть сохранены в отдельный файл. В последствии, этот файл может быть использован в качестве типовой конструкции при применении различных правил или применения конструкции на участке, в качестве шаблона. Также, к примеру, данная функция позволяет передавать созданную конструкцию поперечного профиля из одного проекта в другой.

Для создания файла конструкции текущего поперечника:

1. Выберите элемент меню **Поперечник - Утилиты - Экспортировать конструкцию**.
2. Задайте имя и расположение файла.
3. Нажмите кнопку **Сохранить**.

Для загрузки файла типовой конструкции в текущий поперечный профиль:

1. Выберите элемент меню **Поперечник - Утилиты - Импортировать конструкцию**.
2. Выберите предварительно сохраненный файл конструкции и нажмите кнопку **Открыть**.

Таким образом, эти две команды позволяют создавать файлы типовых поперечников и загружать их.
