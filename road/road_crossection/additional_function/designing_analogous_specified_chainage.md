# Проектирование поперечников аналогично заданному пикету

Иногда возникает ситуация, когда необходимо создать поперечник аналогично уже запроектированному, на каком-либо пикете. Для этого выберите элемент меню **Поперечник - Утилиты - Копировать конструкцию с пикета**, появится следующее окно:

![рис.1](_media/designing_analogous_widths.jpg)

Укажите пикет поперечного профиля, конструкцию которого необходимо применить на текущем поперечнике и нажмите **ОК**.

{% note info %}

 Функция **Проектировать аналогично пикету** работает и для группы выбранных поперечников, для этого необходимо предварительно выбрать пикетажный участок (группу поперечников), на котором должны быть запроектированы поперечники аналогично заданному пикету. 

{% endnote %}
