# Проектирование аналогичных поперечников

При проектировании поперечников зачастую бывает необходимо, чтобы последующий поперечник был спроектирован аналогично предыдущему. Данная функция позволяет быстро и легко создавать аналогичные поперечники.

Для того, чтобы создать последующий поперечник аналогично предыдущему выберите элемент меню **Поперечник - Утилиты - Копировать конструкцию.** Программа автоматически применит конструкцию текущего поперечного профиля на следующем поперечнике.
