# Основные этапы проектирования съезда многоуровневой развязки

1. Комплекс плановых построений, с созданием разбивочной оси, сопрягающейся с полосами дорог, к которым примыкает проектируемый съезд развязки.
2. Создание верха проектной конструкции по съезду развязки, с заданными уклонами полос проезжей части, обочин, виражей и т.п..
3. Оценка первого приближения продольного профиля по съезду. При не возможности выдерживания нормативных требований применительно к профилю съезда он редактируется путем изменения его плановой геометрии. И так до тех пор, пока нормативные требования по продольному профилю съезда не будут выдержаны.
4. Задание основных параметров съезда на участке его сопряжения с основным ходом такие как: параметры ПСП, радиусы сопрягающих кривых и т.п..
5. Построение уточненного, окончательного варианта профиля по съезду.
6. Визуальная оценка корректности планово-высотной увязки съезда развязки с основным ходом.
7. Создание окончательных поперечных профилей, по съезду развязки включая откосы, слои дорожной одежды, водоотводы и т.п..
8. Увязка откосов и кюветов съезда развязки с основным ходом.
9. Формирование выходных ведомостей и чертежей.

Далее подробно рассмотрим каждый из перечисленных этапов.
