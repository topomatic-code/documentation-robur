# Общие сведения

В программе имеется функционал для построения пересечений из отдельных элементов, таких как, островки (треугольные, каплевидные и т.д.), разрывы, переходно-скоростные полосы и т.д. Т.е. из имеющегося набора элементов имеется возможность вручную создать не типовое пересечение.

{% note info %}

На данный момент в программе реализован функционал позволяющий создавать такие элементы как, переходно-скоростная полоса (ПСП), разрыв и дополнительные оси, которые могут описывать положения характерных элементов дороги (кромки, бровки, оси ПСП). В следующих версиях программы набор элементов будет расширяться.

{% endnote %}

Далее рассмотрим последовательность действий по созданию этих элементов.
