# Задать уклон между двумя точками

Функция позволяет задать необходимый продольный уклон на выбранном участке структурной линии.

Для этого:

1. Выберите элемент меню **Площадка – Структурные линии – Задать уклон между двумя точками**. На экране появится графический курсор.

2. Последовательно выберите первую и вторую точку структурной линии.

3. В появившемся динамическом поле введите уклон и нажмите клавишу **Enter**.

4. В результате, относительно указанной первой точки, будет задан продольный уклон на всем участке структурной линии между указанными первой и второй точками.

5. Для завершения нажмите клавишу **Enter** или правую кнопку мыши.
