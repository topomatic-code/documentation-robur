# Задать отметку точкам

Данная функция позволяет задать значение высотной отметки точкам, принадлежащим выбранной структурной линии.

Для этого:

1. Выберите меню **Площадки - Структурные линии – Задать отметку точкам**;

2. Курсор примет форму прицела, укажите структурную линию;

3. В строке динамического ввода введите значение высотной отметки.

Таким образом, все точки структурной линии примут высотные отметки согласно заданному значению.
