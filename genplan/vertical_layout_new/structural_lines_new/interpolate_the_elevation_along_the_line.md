# Интерполировать отметки по линии

Функция предназначена для интерполяции отметок точек структурной линии между двумя заданными узлами выбранной структурной линии. Для этого:

1. Выберите элемент меню **Площадка – Структурные линии – Интерполировать отметки по линии**. Курсор пример форму прицела, укажите левой кнопкой мыши структурную линию, которую необходимо отредактировать;

2. Далее укажите левой кнопкой начальную и конечную точку, определяющие диапазон для интерполирования отметок. В результате отметки всех точек в пределах выбранного участка будут интерполированы.
