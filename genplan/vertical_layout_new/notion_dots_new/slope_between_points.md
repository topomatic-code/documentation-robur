# Задать уклон между точками

Данная функция позволяет задать уклон между выбранными точками.

Для этого:

1. Выберите меню **Площадки – Точки – Задать уклон между точками**, курсор примет форму прицела, **ЛКМ** укажите первую точку.

2. Далее, последующие точки между которыми необходимо задать одинаковое значение уклона можно также указать **ЛКМ** или выбрать их по структурной линии, нажав **ПКМ** и выбрав соответствующую команду.

3. После выбора необходимых точек, для подтверждения нажмите **Enter**.

4. В динамической строке укажите значение уклона. Для подтверждения ввода нажмите **Enter**.
