# Введение

В данном разделе описан основной функционал по созданию и редактированию точек поверхности в модели **Площадка**.
Так как базовые принципы работы с точками поверхности в модели **Площадка** и **ЦММ** аналогичны, то в модели **Площадка**, также может использоваться весь доступный функционал модели **ЦММ**. Основные понятия точек и весь этот функционал описан в разделе по [работе с ЦММ](../../../rb_survey/dtm/sfc/points/notion_dots.md).

Модель типа **Площадка** для работы с точками поверхности включает в себя ряд дополнительных функций, которых нет в модели **ЦММ**, описание которых приведено ниже в следующих разделах:

* [Изменить отметку](change_elevation.md)

* [Задать отметки по опорной точке](elevation_based_on_reference_dot.md)

* [Выровнять отметки по опорной точке](elevation_align_to_reference_dot)

* [Задать отметки по опорной линии](elevation_based_on_reference_line.md)

* [Вставить точки по опорной линии](dots_based_on_reference_line.md)

* [Задать уклон между точками](slope_between_points.md)

* [Указать номера точек](numeration_dots.md)
