# Выровнять отметки по опорной точке

Данная функция позволяет задать отметку точкам относительно опорной точки с необходимым уклоном или превышением.

Для этого:

1. Выберите меню **Площадка – Точки – Выровнять отметки по опорной точке**;
2. Укажите **Уклон** или **Превышение** относительно базовой точки. Для подтверждения ввода нажмите **Enter**;
3. Укажите левой кнопкой мыши базовую точку;
4. Далее последовательно укажите изменяемые точки. Для завершения функции нажмите **Esc**.
