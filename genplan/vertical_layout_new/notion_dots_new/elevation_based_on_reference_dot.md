# Задать отметки по опорной точке

Данная функция позволяет задать отметку точки относительно опорной точки с необходимым уклоном или превышением.

Для этого:

1. Выберите меню **Площадка – Точки – Задать отметки по опорной точке**, курсор примет форму прицела;
2. Укажите левой кнопкой мыши базовую точку;
3. Укажите изменяемую точку;
4. Укажите для изменяемой точки **Уклон** или **Превышение** относительно базовой точки. Для подтверждения ввода нажмите **Enter**.
