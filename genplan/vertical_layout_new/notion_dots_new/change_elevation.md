# Изменить отметку

Данная функция позволяет задать другое значение высотной отметки Z для съемочной точки.

Для этого:

1. Выберите меню **Площадки – Точки – Изменить отметку**, курсор примет форму прицела;
2. Укажите левой кнопкой мыши точку поверхности, отметку которой необходимо отредактировать;
3. В динамической строке задайте новую высотную отметку. Для подтверждения ввода нажмите **Enter**.
