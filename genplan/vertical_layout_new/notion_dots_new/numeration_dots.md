# Указать номера точек

Данная функция позволяет изменить нумерацию точек (точечных объектов) узлов.

Для этого:

1. Выберите меню **Площадки – Точки – Указать номера точек**, введите начальный номер точки;

2. Курсор примет форму прицела, последовательно укажите точки, нумерацию которых необходимо изменить;

{% note info %}

 При необходимости выбора структурной линии, нажмите правой кнопкой мыши и из контекстного меню выберите соответствующую опцию. Курсор примет форму прицела, укажите первую и последнюю точку структурной линии, в диапазоне которых необходимо изменить нумерацию точек.

{% endnote %}

3. Задайте необходимые параметры и нажмите **Enter**.

После проделанных действий программа изменит нумерацию узлов.
