# Вставить точки по опорной линии

Функция предназначена для вставки точек в изменяемую структурную линию перпендикулярно узловым точкам опорной структурной линии.

Для этого:

1. Выберите элемент меню **Площадка – Точки – Вставить точки по опорной линии**. Курсор примет форму прицела;

2. Укажите базовую структурную линию. Курсор будет перемещаться с привязкой к структурной линии, ЛКМ последовательно укажите на опорной линии начальную и конечную точку диапазона;

{% note info %}

 Автоматически может быть выбран вся опорная структурная линия, для этого в меню выбора или в контекстном меню выберите **Выбрать всю линию**.

{% endnote %}

3. Укажите изменяемую структурную линию. На структурной линии добавятся точки перпендикулярно узловым точкам опорной линии. Для завершения функции нажмите **Esc**.
