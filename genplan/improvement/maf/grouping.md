# Объединить в группу

Данный функционал позволяет объединить элементы **МАФ** в одну группу, при этом Выноска для всей группы будет в единичном количестве при выполнении [Автонумерации](autonumbering.md).

{% note info %}

 Элементы МАФ могут входит в одну группу при условии, что их Свойства будут идентичны.

{% endnote %}


Для этого:

1. Выберите элемент меню **МАФ - Группировка - Объединить в группу**;

2. Выберите элементы в окне План. Нажмите клавишу **Enter**.

Таким образом, при выполнении [Автонумерации](autonumbering.md) программа назначит на все элементы группы один общий номер.
