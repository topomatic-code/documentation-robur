# Копировать свойства

Функция позволяет скопировать все свойства с одного элемента **МАФ** на другой. Для этого:

1. Выберите элемент меню **МАФ - Группировка - Копировать свойства**;

2. В окне План выберите элемент МАФ, с которого будут скопированы Свойства. Далее поочередно выберите элементы МАФ, для которых эти свойства должны быть назначены. Нажмите клавишу **Enter**.

В результате программа скопирует Свойства с одного объекта МАФ на другой.
