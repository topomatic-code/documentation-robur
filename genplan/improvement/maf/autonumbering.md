# Автонумерация

Данный функционал позволяет пронумеровать элементы **МАФ**, автонумерация выполняется в порядке возрастания значений по выбранной приоритетной координате (X или Y).

{% note info %}

 Элементы **МАФ** могут иметь единый номер при условии, что их Свойства будут идентичны.

{% endnote %}

Для этого:

1. Выберите элемент меню **МАФ - Группировка - Автонумерация**;

2. Программа предложит выбрать варианты нумерации: По координате X, По координате Y. Задайте необходимый вариант и выберите элементы в окне План. Нажмите клавишу **Enter**.

3. Далее программа предложить **Продолжить нумерацию с числа** выберите Да/Нет. При выборе Нет задайте числовое значение, с которого будет проставлена автонумерация.

Программа автоматически пронумерует выбранные элементы МАФ через Выноску по примитиву.
