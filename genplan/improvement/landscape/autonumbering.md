# Автонумерация

Данный функционал позволяет проставить одинаковую автонумерацию элементов Озеленения с одинаковым **Типом посадки**.

{% note info %}

 Элементы Растения могут иметь единый номер при условии, что их значения Свойств будут идентичны. Данные группы Свойств задаются через [Свойства элементов Озеленения](landscaping_properties.md).

{% endnote %}


1. Выберите меню **Озеленение - Группировка - Автонумерация**;

2. Программа предложит выбрать варианты автонумерации:

* **По координатам и типу (сначала лиственные)** - приоритетность в нумерации отдается элементам **Озеленения** с Типом растения - **Лиственные**, при этом Тип растения - **Дерево** будет иметь большую приоритетность, чем Тип растения - **Кустарник**. Внутри каждой категории нумерация производится в порядке расположения элементов по координатам X и Y.

* **По координатам и типу (сначала хвойные)** - приоритетность в нумерации отдается элементам **Озеленения** с Типом растения - **Хвойные**, при этом Тип растения - **Дерево** будет иметь большую приоритетность, чем Тип растения - **Кустарник**. Внутри каждой категории нумерация производится в порядке расположения элементов по координатам X и Y.

* **По координатам** - нумерация производится в порядке расположения элементов **Озеленения** по координатам X и Y.

* **По наименованию (сначала лиственные)** - приоритетность в нумерации отдается элементам **Озеленения** с Типом растения - **Лиственные**, при этом Тип растения - **Дерево** будет иметь большую приоритетность, чем Тип растения - **Кустарник**. Внутри каждой категории нумерация производится в алфавитном порядке наименований элементов **Озеленения**.

* **По наименованию (сначала хвойные)** - приоритетность в нумерации отдается элементам **Озеленения** с Типом растения - **Хвойные**, при этом Тип растения - **Дерево** будет иметь большую приоритетность, чем Тип растения - **Кустарник**. Внутри каждой категории нумерация производится в алфавитном порядке наименований элементов **Озеленения**.

* **По наименованию** - нумерация производится в алфавитном порядке наименований элементов **Озеленения**.

3. Задайте необходимый вариант и выберите элементы в окне План. Нажмите клавишу **Enter**.

Программа автоматически пронумерует выбранные элементы через круглую выноску. Верхнее числовое значение выноски обозначает порядковый **Номер** элемента, нижнее числовое значение выноски обозначает **Кол-во растений, шт** в выбранном **Типе посадки**.

* Настроить видимость выноски автонумерации и отредактировать порядковый **Номер** можно в [Свойства элементов Озеленения](landscaping_properties.md).

* Настроить отображение выноски ( Цвет, Фон, Стиль и т.д.) можно через настройки [Стилей озеленения](general.md).
