# Выноски с наименованием

Данный функционал позволяет автоматически создать выноски с **Наименованием** по всем элементам Озеленения текущей модели **Площадка**. Для этого:

* Выберите элемент меню **Озеленение - Группировка - Выноски с наименованием**.

Редактирование **Выноски по примитиву** (Общее, Текст, Геометрия) возможно через её **Свойства**.
