# Группировка

Данный функционал позволяет объединить элементы Озеленения с Типом посадки **Точечная посадка** в одну **Групповую посадку** для общей [Автонумерации](autonumbering.md).

{% note info %}

 Элементы **Озеленения** могут попасть в одну группу при условии, что их значения Свойств будут идентичны. Данные Свойства задаются через [Свойства элементов Озеленения](landscaping_properties.md).

{% endnote %}


## Объединить в группу

Для объединения элементов Озеленения в группу:

1. Выберите элемент меню **Озеленение - Группировка - Объединить в группу**;

2. Программа предложит выбрать объекты для объединения в группу. Укажите объекты поочередно, либо выберите область объединения. Нажмите клавишу **Enter**.

Программа объединит растения в группы по идентичным свойствам.

Таким образом, при выполнении [Автонумерации](autonumbering.md) программа назначит на все элементы группы одну общую выноску с номером.

## Разбить группу

Данная функция позволяет разбить выделенную группу на отдельные элементы Озеленения с Типом посадки Точечная посадка. Для этого:

1. Выберите элемент меню **Озеленение - Группировка - Разбить группу**;

2. Укажите объект группа, нажмите клавишу **Enter**.

## Присоединить к группе

Данная функция позволяет присоединить к уже созданной группе элемент Озеленения с Типом посадки Точечная посадка. Для этого:

1. Выберите элемент меню **Озеленение - Группировка - Присоединить к группе**;

2. В окне План выберите группу, далее выберите элемент Озеленения, который необходимо присоединить. При нажатии клавиши **Shift** возможно присоединение нескольких элементов Озеленения.

{% note info %}

 Возможно редактирование группы элементов Озеленения через грипы осевой линии (полилинии). Для этого выберите группу в окне План, нажмите ПКМ на грип:

 * Через функцию **Удалить вершину** возможно удаление единичного элемента Озеленения из группы. При этом сам элемент не удалится, а станет элементом Озеленения с Типом посадки Точечная посадка.
 * Через функцию **Добавить вершину** возможно добавление единичного элемента Озеленения в группы.
 * Функция **Упорядочить** позволяет перегруппировать элементы Озеленения, то есть осевая линия (полилиния) группы будет строиться по возрастанию координат.

{% endnote %}
