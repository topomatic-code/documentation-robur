# Копировать свойства

Функция позволяет скопировать свойства элементов **Озеленения**. Для этого:

1. Выберите меню **Озеленение - Группировка - Копировать свойства**;

2. В окне План выберите элемент Озеленения, с которого будут скопированы Свойства. Далее поочередно выберите элементы Озеленения, для которых были скопированы Свойства. Нажмите клавишу **Enter**.

В результате программа скопирует Свойства с одного объекта Озеленения на другой.

{% note info %}

 Свойства элементов Озеленения с Типом посадки Живая изгородь копируются только на идентичный Тип посадки.

{% endnote %}
