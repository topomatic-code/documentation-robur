# Введение

Функционал **Озеленение** позволяет осуществить расстановку элементов Озеленения, произвести автонумерацию и на основе этого создать выходную документацию - чертежи планов и ведомости, а также информационную модель. 

По умолчанию в программе встроены Библиотека элементов (3D моделей), Библиотека нормативных документов, Библиотека комов и ямов для различных регионов.
