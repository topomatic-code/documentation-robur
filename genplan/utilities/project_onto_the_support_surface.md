# Спроецировать на опорную поверхность

Функция позволяет спроецировать все точки поверхности текущей модели Площадки на **Опорную поверхность**, то есть отметка (Z) каждой точки будет вычислена по **Опорной поверхности**.

{% note info %}

 **Опорная поверхность** задается в [Настройках модели Площадка](../creating_ground_model.md), которые были подробно описаны ранее. 

{% endnote %}

Для этого:

1. Выберите функцию меню **Площадки - Утилиты – Спроецировать на опорную поверхность**. Программа отправит уведомление о том, данная функция изменит отметки у всех точек модели Площадка:

![genplannew_16.png](_media/genplannew_16.png)

2. Нажмите кнопку **Да**. Программа изменит у всех точек поверхности отметки согласно выбранной Опорной поверхности. Точка изменит отметку только в том случае, если проекция попадает на Опорную поверхность.

{% note info %}

 Проецирование на опорную поверхность выполняется последовательным выбором следующих команд: [Копировать точки из опорной поверхности](copy_dots_from_a_reference_surface.md) -> [Создать поверхность из примитивов](creating_surface_from_primitives.md) -> [Копировать структурные линии из опорной поверхности](copy_structural_lines_from_reference_surface.md) -> [Спроецировать на опорную поверхность](project_onto_the_support_surface.md)

{% endnote %}
