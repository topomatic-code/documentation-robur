# Копировать структурные линии из опорной поверхности

Данная функция предназначена для копирования *структурных линий* и *полигонов* из **Опорной поверхности** в текущую модель Площадка .

{% note info %}

 1. Функция используется в рамках решения задачи по проецированию модели Площадка на [Опорную поверхность](project_onto_the_support_surface.md).

 2. **Опорная поверхность** задается в [Настройках модели Площадка](../creating_ground_model.md), которые были подробно описаны ранее.

{% endnote %}


Для этого:

1. Выберите элемент меню **Площадки - Утилиты - Копировать структурные линии из опорной поверхности**. Программа отправит уведомление о том, что все примитивы, относящиеся к слою **Характерные линии**, будут удалены:

![](_media/genplannew_15.png)

2. Нажмите кнопку **Да**. Программа перенесет структурные линии и полигоны из Опорной поверхности в слой **Характерные линии**. Узловые точки структурных линий будут иметь отметки равные нулю.
