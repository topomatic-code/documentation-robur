# Копировать семантические свойства

Данная функция позволяет скопировать семантический код и его заданные характеристики с одного объекта на другие участки (объекты).

Для этого:

1. Выберите элемент меню **Площадки - Утилиты - Копировать семантические свойства**;

2. Курсор примет форму прицела, левой кнопкой мыши укажите на плане исходный объект, с которого будет скопирован семантический код, далее левой кнопкой мыши укажите участки (объекты), на которые будут скопирован семантический код. Нажмите клавишу **Enter**.

В результате, семантический код будет скопирован на все выбранные участки (объекты).
