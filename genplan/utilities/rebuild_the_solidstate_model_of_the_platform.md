# Перестроить твердотельную модель площадки

Функция предназначена для создания твердых (объемных) тел по ранее заданным слоям, объемам насыпи и выемки, бортовым камням и т.п.

Для того чтобы сформировать объемные тела:

1. Выберите элемент меню **Площадки** - **Утилиты** - **Перестроить твердотельную модель площадки**;

2. Программа отправит уведомление об **Удалении примитивов со слоёв Объемы**, выберите **Да**. Программа отправит данное уведомление даже в том случае, если Объемы ранее не были созданы. Объемные тела будут созданы между проектной поверхностью и поверхностью черной земли - по контуру пересечения данных поверхностей.

{% note info %}

Так как функция **Перестроить твердотельную модель площадки** не является динамической при изменении элементов поверхности **Площадки** и её **Слоев** необходимо повторно использовать функцию и удалить ранее созданные примитивы со слоёв Объемы для получения актуальных данных.

{% endnote %}


Вместе с объемными телами будет создан слой **Объемы|Название**, на котором будет находится модель объема.

{% note info %}

 Данной функцией строятся объемные тела модификаторов [Слои](../../genplan/vertical_layout_new/design_plan_genplan/layers.md), **Бортовые камни** (через назначенный Семантический код с атрибутом **Объект информационной модели**), твердые тела по атрибуту семантики **Контроллер КДО**, объемные тела по **Насыпи/Выемки**.

{% endnote %}
