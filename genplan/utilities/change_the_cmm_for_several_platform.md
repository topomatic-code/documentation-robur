# Изменить ЦММ у нескольких площадок

Данная функция позволяет задать/переназначить модель ЦММ для выбранных моделей Площадок. Данная функция имеет приоритет перед заданной моделью ЦММ в [Настройках модели Площадка](../creating_ground_model.md). Для этого:

1. Выберите элемент меню **Площадки - Утилиты - Изменить ЦММ у нескольких площадок**;

2. Откроется диалоговое окно с двумя разделами:

* **Модели** - из списка моделей Площадка выберите те модели, которым необходимо назначить/переназначить модель ЦММ.
* **ЦММ** - из списка моделей ЦММ выберите те модели, которые будут являться фактическими для проектного площадного объекта.

3. После выбора объектов нажмите клавишу **ОК**.

{% note info %}

При совместной работе или работе на сервере/в облаке, ЦММ будет меняться только на разблокированных и не занятых моделях. Более подробно принцип [Коллективной работы над проектом](../../commons_tasks/collaborate/section_description.md) описан в соответствующем разделе.

{% endnote %}
