# Импорт данных из CAD-систем

Горизонтальная планировка объекта генерального плана может быть импортирована из файлов чертежей в форматах DXF\DWG, созданных в других графических редакторах, например АutoCAD.

Имеется несколько способов загрузки:

1. Для импорта всех данных из файла (dxf\dwg), используйте функцию **Проект - Импортировать - Ситуация**

2. Для импорта отдельных элементов чертежа, уже открытого в другом графическом редакторе, используйте функцию **Рисовать - Внешний редактор - Импорт**.

В результате, данные (примитивы) импортируются с исходными характеристиками (цвет, слой и т.д.) и отобразятся в окне **План**:
